تولۇق باشلاش قوللانمىسى

HexClaw AI تولۇق قوللانمىسى: 5 مىنۇتتا نۆلدىن باشلاپ سىزگە ئىش قىلىدىغان يەرلىك AI Agent غىچە(مودېل تاللاش تەۋسىيەلىرى بىلەن)

يەرلىك Ollama ياكى بۇلۇت API نى نۆلدىن سەپلەش، Agent ياردەمچى قۇرۇش، بىلىم ئامبىرى ۋە Skill يۈكلەش. 5 مىنۇتتا ئۆزىڭىزگە تەۋە شەخسىي ئۈستەل يۈزى AI ياردەمچىسىنى باشلاڭ.

تۇنجى نەشرى WeChat تا بۇ ماقالە تۇنجى قېتىم WeChat ئاممىۋى ھېساباتى 「hexclaw」 (ID: hexclaw) نىڭ رەسمىي تېخنىكا سەھىپىسىدە ئېلان قىلىنغان · ۋاقتى: 2026-يىلى 4-ئاينىڭ 12-كۈنى · ئوقۇش ۋاقتى تەخمىنەن 10 مىنۇت
WeChat تىكى ئەسلى ماقالە ↗

ئالدىنقى ماقالىدە HexClaw AI نىڭ ئالتە ئامبىرىنى ئايرىپ، تۆۋەنكى رامكىدىن ئۈستەل يۈزى خېرىدارىغىچە ئارخىتېكتۇرىنى قاتلاممۇقاتلام چۈشەندۈرگەن ئىدۇق.

ئارخىتېكتۇرىنى چۈشەنگەن بىلەن، مەھسۇلاتنىڭ قولايلىق ياكى ئەمەسلىكىنى ئۆز قولىمىز بىلەن ئىشلىتىپ باقماي بىلگىلى بولمايدۇ. بۇ ماقالە پرىنسىپنى ئەمەس، پەقەت مەشغۇلاتنى چۈشەندۈرىدۇ — قاچىلاشتىن AI غا ھۆججەت ئوقۇتۇش، بىلىم ئامبىرىدىن ئىزدەش، Feishu غا ئۇلاشقىچە 5 مىنۇتتا بىر قېتىم ئۆتۈپ چىقىمىز.

ئوقۇپ بولغاندا، كومپيۇتېرىڭىزدا ئىجرا بولىدىغان AI Agent غا ئىگە بولىسىز: سانلىق مەلۇمات كومپيۇتېردىن چىقمايدۇ، ھەقسىز، ئوچۇق كودلۇق.

قاچىلاش: بىر قۇر بۇيرۇق

رەسمىي تور بېكەتتىن چۈشۈرۈش: hexclaw.net(توركۆرگۈچكە كۆچۈرۈپ ئېچىڭ؛ macOS / Windows / Linux نىڭ ھەممىسىنى قوللايدۇ)

macOS：

brew tap hexagon-codes/tap && brew install --cask hexclaw

Homebrew قاچىلانمىغانمۇ؟ curl ئىشلىتىڭ:

curl -fsSL https://raw.githubusercontent.com/hexagon-codes/hexclaw-desktop/main/install.sh | bash

Windows / Linux： hexclaw.net بېتىدىن ماس قاچىلاش بوغچىسىنى (.exe / .deb / .AppImage) چۈشۈرۈپ، قوش چېكىپ قاچىلاڭ.

قاچىلىغاندىن كېيىن HexClaw AI نى ئاچسىڭىز، سەپلىمە يېتەكچىسى چىقىدۇ. ئۈچ باسقۇچ، 30 سېكۇنتتا تامام.

سەپلەشتىن تۇنجى سۆھبەتكىچە

مودېل تاللاڭ. HexClaw AI، OpenAI، DeepSeek، Zhipu، Qwen ۋە Ollama يەرلىك مودېللىرىنى قوللايدۇ. API Key نى كىرگۈزۈپ، «测试连接» (ئۇلىنىشنى سىناش) نى چېكىڭ؛ مۇۋەپپەقىيەتلىك ئۆتسە بولدى.

رول تاللاڭ. ئومۇمىي ياردەمچى، كود ياردەمچىسى، يېزىقچىلىق ياردەمچىسى — بۇ AI نىڭ سۈكۈتتىكى مىجەزىنى بەلگىلەيدۇ؛ كېيىن خالىغان ۋاقىتتا ئالماشتۇرالايسىز.

جەزملەپ باشلاڭ. سەپلىمە خۇلاسىسىنى تەكشۈرۈپ، «开始使用» (ئىشلىتىشنى باشلاش) نى چېكىڭ.

ئاساسىي كۆرۈنمە يۈزىگە كىرگەندە، ئومۇمىي كۆرۈنۈش بېتىدە ئىشلىتىش سانلىق مەلۇماتى ۋە كۆپ ئىشلىتىلىدىغان خىزمەت ئېقىملىرى كۆرۈنىدۇ:

سەپلىمە تەييار بولسا، بىۋاسىتە پاراڭلىشىڭ. پاراڭ بېتىنى ئاچسىڭىز، كىچىك قىسقۇچپاقا ئالدى بىلەن سالام بېرىدۇ:

مەن «خاڭجۇ تاماقلىرىنى قانداق يېيىش توغرا؟» دەپ سورىدىم. كىچىك قىسقۇچپاقا بىلىم ئامبىرىدىكى ھۆججەتلەرنى ئاپتوماتىك ئىزدەپ، نەقىل مەنبەسى بار جاۋاب بەردى:

پاراڭ رامكىسىنىڭ ئاستىغا قاراڭ: مودېل بەلگىسى ھازىر qwen3.5:9b (يەرلىك مودېل) ئىشلىتىلىۋاتقانلىقىنى كۆرسىتىدۇ؛ چېكىپ ئالماشتۇرغىلى بولىدۇ؛ چوڭقۇر پىكىر يۈرگۈزۈش ئالماشتۇرغۇچىسى مودېلنى ئالدى بىلەن پىكىر يۈرگۈزۈپ ئاندىن جاۋاب بېرىشكە قويىدۇ؛ قەغەز قىسقۇچ بەلگىسى ئارقىلىق سۈرەت ۋە PDF يۈكلەپ، AI غا بىۋاسىتە ئوقۇتۇپ تەھلىل قىلدۇرغىلى بولىدۇ.

تۇنجى ئۇچۇرنى ئەۋەتكەن ھامان ئىشلىتىش باشلانغان بولىدۇ. لېكىن پاراڭ پەقەت باشلىنىش؛ HexClaw AI نىڭ ئەڭ قىزىقارلىق يېرى، ئۇنىڭ سىزگە ھەقىقىي ئىش قىلىپ بېرىشى。

قورال چاقىرىش: AI پەقەت ئېغىزدا سۆزلىمەيدۇ

مەن «hexclaw مۇندەرىجەمدە قانداق ھۆججەتلەر بار؟» دەپ سورىدىم؛ كىچىك قىسقۇچپاقا list_directory قورالىنى چاقىرىپ، ھەقىقىي يەرلىك ھۆججەت سىستېمىسىنى ئوقۇدى:

بۇ توقۇلما ئەمەس، ھەقىقىي ئوقۇلغان نەتىجە. قورال چاقىرىش نەتىجىسى ئۇچۇر ئاستىدا يىغىق كۆرسىتىلىدۇ؛ كېڭەيتسىڭىز تولۇق مەزمۇننى كۆرەلەيسىز.

قورال چاقىرىشنىڭ ئارقىسىدىكى مېخانىزم MCP (Model Context Protocol) دەپ ئاتىلىدۇ. ئۇنى ھەممىباب USB ماسلاشتۇرغۇچ دەپ تەسەۋۋۇر قىلسىڭىز بولىدۇ: AI ھۆججەت سىستېمىسىنى مەشغۇلات قىلماقچى بولسا filesystem ماسلاشتۇرغۇچىنى، ساندان ئىزدىمەكچى بولسا database ماسلاشتۇرغۇچىنى چېتىدۇ. HexClaw AI، MCP نى ئەسلىدىن قوللايدۇ؛ سەپلىسىڭىزلا ئىشلىتىدۇ، كود يېزىش كېرەك ئەمەس.

پۈتكۈل جەريان ئاپتوماتىك: سىز ئۇچۇر ئەۋەتىسىز → LLM قايسى قورالنى چاقىرىشنى بەلگىلەيدۇ → ماتور تەلەپنى ماس MCP Server غا يوللايدۇ → ئىجرا نەتىجىسى قايتىدۇ → LLM نەتىجىگە ئاساسەن جاۋاب ھاسىل قىلىدۇ. بىر قەدەم يېتەرلىك بولمىسا، ھالقا داۋاملىشىدۇ: ئالدى بىلەن ئىزدەيدۇ، ئاندىن ئوقۇيدۇ، ئاخىرى خۇلاسىلەيدۇ؛ ئاخىرقى جاۋاب چىققۇچە ئارقا-ئارقىدىن چاقىرىدۇ. بۇ ئالدىنقى ئارخىتېكتۇرا سۈرىتىدىكى ReAct قورال ھالقىسى。

ئاندىن مەن يەنە «ئۆتكەن يىلى نېمە سېتىۋالغان ئىدىم؟» دەپ سورىدىم — بۇنى بۇرۇنقى پاراڭدا ئېغىز ئۇچىدا ئېيتقان ئىدىم. كىچىك قىسقۇچپاقا ئەستە ساقلاپتۇ:

ئۇ بۇرۇنقى سۆھبەتنى ئەسلەپ، توغرا جاۋاب بەردى. بۇ پەقەت كونتېكىست كۆزنىكىگە تايىنىش ئەمەس، بەلكى ئۇزاق مۇددەتلىك ئەستە ساقلاش — ئۇچۇر ھەقىقىي ساقلانغان، يېڭى سۆھبەتتىمۇ قايتا ئەسلىگىلى بولىدۇ. ئەستە ساقلاشنىڭ قانداق ئىشلەيدىغانلىقىنى كېيىنكى بۆلەكتە سۆزلەيمىز.

بىلىم ئامبىرى ۋە ئەستە ساقلاش: AI نىڭ ئىككى خىل «ئەستە تۇتۇشى»

كىچىك قىسقۇچپاقا نەرسىلەرنى ئىككى خىل ئۇسۇلدا «ئەستە تۇتىدۇ»: بىرىنى سىز مەخسۇس بېرىسىز، يەنە بىرىنى ئۇ ئۆزى ئۆگىنىدۇ.

بىلىم ئامبىرى: سىز يۈكلەيسىز، ئۇ مەنبەگە ئاساسەن جاۋاب بېرىدۇ.بىلىم ئامبىرى بېتىنى ئېچىپ، PDF، TXT ياكى Markdown نى تاشلاڭ؛ ئىندېكس ئاپتوماتىك قۇرۇلىدۇ:

ئۇنىڭدىن كېيىن پاراڭلاشقاندا، AI ۋېكتورلۇق ئىزدەش بىلەن ھۆججەتلىرىڭىزدىن ئەڭ مۇناسىۋەتلىك ئابزاسلارنى تېپىپ، كۆرسەتمىگە قوشىدۇ. يۇقىرىدىكى «خاڭجۇ تامىقى» جاۋابىمۇ بىلىم ئامبىرىدىن تېپىلغان؛ AI قۇرۇق توقۇمايدۇ، بەلكى مەنبەگە ئاساسلىنىدۇ. بۇ RAG، يەنى ئىزدەش بىلەن كۈچەيتىلگەن ھاسىل قىلىش.

ئەستە ساقلاش: پاراڭدىكى مۇھىم ئۇچۇر ئاپتوماتىك ساقلىنىپ، ئاپتوماتىك قايتا ئەسلىنىدۇ.

سۆھبەت ئاخىرلاشقاندىن كېيىن، ماتور مەزمۇننى ئاسىنخرون تەھلىل قىلىپ، ئەستە تۇتۇشقا ئەرزىيدىغان ئۇچۇرنى ئايرىپ چىقىرىدۇ. كېيىنكى پاراڭدا مۇناسىۋەتلىك ئەسلىمىلەرنى كونتېكىستقا ئاپتوماتىك قوشىدۇ؛ كىچىك قىسقۇچپاقا شۇنىڭ بىلەن «ئېسىگە ئالىدۇ». سىز قولدا قوشۇش، تەھرىرلەش ۋە ئۆچۈرۈشنىمۇ قىلالايسىز.

ئاددىي ئېيتقاندا، بىلىم ئامبىرى سىرتقى ماتېرىيال ئامبىرى، ئەستە ساقلاش بولسا AI نىڭ خاتىرە دەپتىرى. بىرى ھۆججەتنى، يەنە بىرى پاراڭنىڭ مۇھىم نۇقتىلىرىنى ساقلايدۇ.

بۇ يەرگىچە پاراڭ، قورال چاقىرىش، بىلىم ئامبىرى ۋە ئەستە ساقلاشنى كۆردىڭىز. سىز كىرگۈزگەندىن AI جاۋاب بەرگۈچە ئارىلىقتا قانچە قەدەم بارلىقىغا قىزىقامسىز؟ تۆۋەندىكى سۈرەت تولۇق بىر تەرەپ قىلىش زەنجىرى：

قارىماققا ئۇزۇن، لېكىن ماتور بۇ باسقۇچلارنى مىللىسېكۇنت دەرىجىسىدە تاماملايدۇ؛ سىز ھېس قىلىدىغىنىڭىز «ئېقىم شەكلىدە خەت يېزىلىش».

IM قانىلى: گۇرۇپپا Feishu دا بىۋاسىتە @ قىلىدۇ

گۇرۇپپىڭىز بولسا، ھەممە كىشىگە خېرىدار قاچىلىتىش ھاجەتسىز. HexClaw AI نى Feishu، DingTalk، Discord، Telegram غا ئۇلاپ، IM قانىلى بېتىدە قوزغىتىڭ؛ يېشىل رەڭ ئىجرا بولۇۋاتقانلىقىنى بىلدۈرىدۇ:

ئاندىن Feishu دا ئۇنى @ قىلسىڭىزلا بولدى. مەن «ئايرىلىپ كەتكەن خىزمەتدىشىمىز نەگە بارغان؟» دەپ سورىدىم؛ ئۇ بىلىم ئامبىرىنى ئىزدەپ جاۋاب بەردى:

Feishu ماشىنا ئادىمى «پىكىر يۈرگۈزۈۋاتىدۇ» ھالىتىنى كۆرسىتىپ، جاۋاب تەييار بولغاندا ئاپتوماتىك ئەۋەتىدۇ. گۇرۇپپا ئەزالىرى Feishu دا بىۋاسىتە ئىشلىتىدۇ؛ قوشۇمچە قاچىلاش ھاجەتسىز.

Feishu ماشىنا ئادىمىنى سەپلەش (3 مىنۇت)

HexClaw AI نى Feishu دا كۆرسىتىش ئۈچۈن، Feishu ئوچۇق سۇپىسى دا ئۆزىڭىز قۇرغان بىر ئەپ لازىم. جەريان مۇرەككەپ ئەمەس:

1. ئەپ قۇرۇپ، كىملىك ئۇچۇرىنى ئېلىڭ.Feishu ئوچۇق سۇپىسىغا كىرىپ، كارخانا ئۆزى قۇرغان ئەپ قۇرۇڭ. «凭证与基础信息» (كىملىك ئۇچۇرى ۋە ئاساسىي ئۇچۇر) بېتىدىن App ID ۋە App Secret：

2. ئىجازەتلەرنى سەپلەڭ.«权限管理» (ئىجازەت باشقۇرۇش) بېتىدە «批量导入/导出权限» (ئىجازەتلەرنى توپلاپ كىرگۈزۈش/چىقىرىش) نى چېكىپ، تۆۋەندىكى JSON نى چاپلاڭ. ئۇچۇر قوبۇل قىلىش ۋە ئەۋەتىش، گۇرۇپپا/شەخسىي پاراڭنى ئوقۇش، بايلىق ھۆججەتلىرى، گۇرۇپپا ئۇچۇرى، ئىشلەتكۈچى ئۇچۇرى، ھۆججەت ئوقۇش قاتارلىق تولۇق ئىجازەتلەرنى بىر قېتىمدا كىرگۈزىدۇ:

3. ھادىسە مۇشتەرىلىكىنى سەپلەڭ.«事件与回调» (ھادىسە ۋە قايتۇرما چاقىرىش) بېتىدە، «使用快速通道 接收事件» (تېز قانال ئارقىلىق ھادىسە قوبۇل قىلىش) نى تاللاپ، im.message.receive_v1 ھادىسىسىنى قوشۇڭ (گۇرۇپپا ۋە شەخسىي پاراڭ ئۇچۇرلىرىنى قوبۇل قىلىدۇ):

4. نەشرىنى ئېلان قىلىڭ.«版本管理与发布» (نەشر باشقۇرۇش ۋە ئېلان قىلىش) بېتىدە نەشر قۇرۇپ، ئۈستەل يۈزىنىڭ سۈكۈتتىكى ئىقتىدارىنى «机器人» (ماشىنا ئادەم) قىلىپ، ئېلان قىلىشقا تاپشۇرۇڭ:

5. HexClaw AI غا قايتىڭ.IM قانىلى بېتىدە يېڭى Feishu نۇسخىسى قۇرۇپ، App ID بىلەن App Secret نى تولدۇرۇپ قوزغىتىڭ. يېشىل «运行中» (ئىجرا بولۇۋاتىدۇ) نى كۆرسىڭىز، تەييار بولدى.

DingTalk / Discord / Telegram نى ئۇلاش جەريانى ئوخشاش: ماس سۇپىدا ماشىنا ئادەم ئەپى قۇرۇپ، كىملىك ئۇچۇرىنى ئېلىپ، HexClaw AI نىڭ IM قانىلى سەپلىمە بېتىگە تولدۇرۇڭ.

مودېل سەپلىمىسى: بۇلۇت + يەرلىك، تاللاش ئۆزىڭىزدە

HexClaw AI بىرلا ۋاقىتتا كۆپ مودېل سەپلەش نى قوللاپ، سىياسەتكە ئاساسەن ئاپتوماتىك يوللايدۇ. سەپلىمە بېتى ئۈستىدە سۈكۈتتىكى مودېل ۋە يوللاش سىياسىتىنى (تەننەرخ ئالدىنقى / سۈپەت ئالدىنقى) تاللاپ، ئاستىدا تەمىنلىگۈچىلەرنى باشقۇرالايسىز:

سانلىق مەلۇماتنىڭ كومپيۇتېردىن چىقىشىنى خالىمامسىز؟ يەرلىك مودېل ئىشلىتىڭ. HexClaw AI غا Ollama باشقۇرۇشى قوشۇلغان؛ مودېلنى ئىزدەپ بىۋاسىتە چۈشۈرەلەيسىز:

ھەقسىز، تورسىز، سانلىق مەلۇمات كومپيۇتېردىن چىقمايدۇ. ئەپ قوزغالغاندا ئاپتوماتىك ئالدىن تەييارلىنىدۇ، ئاچسىڭىزلا پاراڭلىشالايسىز. قايسى مودېلنى تاللاش ۋە قانداق قاتتىق دېتال كېرەكلىكى ھەققىدە، ماقالە ئاخىرىدىكى قوشۇمچىدا تەپسىلىي تەۋسىيە جەدۋىلى بار.

ئاساسىي پىكىر بىرلا: بۇلۇت بىلەن يەرلىكنىڭ ئىككىسىنى سەپلەڭ، يوللاش سىياسىتىنى «تەننەرخ ئالدىنقى» قىلىڭ؛ ئاددىي سوئال يەرلىك ھەقسىز مودېلغا، مۇرەككەپ سوئال ئاپتوماتىك بۇلۇتقا يوللىنىدۇ. سەزگۈر سانلىق مەلۇماتلىق سىنارىيەدە باشتىن-ئاخىر يەرلىكنى ئىشلىتىڭ؛ بىر API تەلىپىمۇ كومپيۇتېرىڭىزدىن چىقمايدۇ.

Skill بىلەن MCP: يۇقىرى ۋە تۆۋەن قاتلاملىق ئىككى كېڭەيتىش

HexClaw AI نىڭ قىلالايدىغان ئىشلىرى قاتتىق بەلگىلەپ قويۇلمىغان؛ ئۇنىڭ ئىككى كېڭەيتىش مېخانىزمى بار.

Skill (ماھارەت) يۇقىرى قاتلامدىكى رول: Markdown بىلەن قوزغىلىش شەرتى، سىستېما كۆرسەتمىسى ۋە ئىشلىتىدىغان قوراللىرىنى بەلگىلەيدۇ. cron-scheduler ماھارىتىنى قاچىلىغاندىن كېيىن، «ھەر كۈنى سائەت 10 دا خەۋەر يىغىپ بەر» دېسىڭىز، AI بۇ Skill نى ئاپتوماتىك چاقىرىپ ۋاقىتلىق ۋەزىپە قۇرىدۇ. ماھارەتنىڭ بارلىقىنى بىلىشىڭىز شەرت ئەمەس؛ ئىشلىتىش-ئىشلەتمەسلىكنى AI ئۆزى بەلگىلەيدۇ.

MCP（Model Context Protocol） تۆۋەنكى قاتلامدىكى قول-پۇت: ھەر بىر MCP Server بىر گۇرۇپپا قورالنى تەمىنلەيدۇ؛ ماتور قوزغالغاندا بارلىق قورال ئېنىقلىمىسىنى ئاپتوماتىك يىغىدۇ، AI لازىم بولغاندا چاقىرىدۇ. تۆۋەندىكىسى ئەپ ئىچىدىكى filesystem MCP Server؛ ئۇ 14 قورال تەمىنلەيدۇ:

مىسالغا ئالساق، Skill — «كەسپىي بوغالتىر تەكلىپ قىلىش»، MCP — «بوغالتىرغا ھېسابلىغۇچ ۋە Excel بېرىش». بىرى رول بىلەن سىياسەتنى بەلگىلەيدۇ، يەنە بىرى كونكرېت مەشغۇلات ئىقتىدارى بىلەن تەمىنلەيدۇ. پەقەت بىرىنىلا ئىشلىتىشكە بولىدۇ، لېكىن ئىككىسىنى بىرلەشتۈرۈش ئەڭ كۈچلۈك。

Agent لار ۋە ئوچۇق كودلۇق ئېكولوگىيە

HexClaw AI ئىچىدە 6 ئالدىن تەڭشەلگەن Agent بار: سانلىق مەلۇمات تەھلىلچىسى، كود ياردەمچىسى، تەتقىقات تەھلىلچىسى، تەرجىمان، يېزىقچىلىق ياردەمچىسى. «聊天» (پاراڭ) نى چېكىپ رولنى بىۋاسىتە ئالماشتۇرىسىز؛ ھەر بىر Agent نىڭ سىستېما كۆرسەتمىسى ۋە ھەرىكەت ئەندىزىسى پەرقلىق:

بۇلارنىڭ ئارقىسىدا تولۇق ئوچۇق كودلۇق ئېكولوگىيە بار: 7 ئامبار قاتلاملار بويىچە ئايرىلغان، تۆۋەنكى ئۇل قۇرۇلمىدىن يۇقىرىقى خېرىدارغىچە ھەر بىر قاتلامنى مۇستەقىل ئىشلىتىشكە بولىدۇ:

پەقەت ئۈستەل يۈزى خېرىدارىنى ئىشلىتەلەيسىز، ياكى hexagon رامكىسى بىلەن ئۆز Agent ىڭىزنى ياسىيالايسىز. ئوچۇق كودلۇق، ھەقسىز، سانلىق مەلۇماتىڭىزغا ئۆزىڭىز ئىگە。

يەرلىك مودېل كىمگە ماس كېلىدۇ؟ئادۋوكات، دوختۇر، پۇل مۇئامىلە خادىملىرى، كارخانا ئىچىدىكى ئىشلار — سانلىق مەلۇمات مەخپىيەتلىكىگە تەلىپى بار ھەر قانداق سىنارىيە. پاراڭ مەزمۇنى، بىلىم ئامبىرى ھۆججەتلىرى ۋە ئەستە ساقلاش سانلىق مەلۇماتى يەرلىك SQLite دا ساقلىنىدۇ، ئۈچىنچى تەرەپ مۇلازىمېتىرىدىن ئۆتمەيدۇ.

سوۋغا: بۇرۇنقى leader.skill 🐍

ئاخىرىدا بىر كىچىك سوۋغا.

مەن بۇرۇنقى رەھبىرىمنى بىر HexClaw AI Skill。

توغرا، دەل شۇنداق ئادەم: ئادەتتە كود يازمايدۇ، ئاندا-ساندا كۇنۇپكا تاختىسىغا تەگسە پۈتۈن گۇرۇپپىنى بىر ھەپتە ئىسمېنا قوشۇشقا مەجبۇر قىلىدۇ. HRBP بىلەن بىرلىشىپ ئىشچىنى تۆلەمسىز ئىشتىن بوشىتىدۇ، سىناق مەزگىلىدە يېڭىلارنى ھەقسىز ئىشلىتىدۇ، قول ئاستىدىكىلەرگە PUA قىلىدۇ، نەتىجە باھاسى بىلەن بېسىدۇ، مەسئۇلىيەتنى ئىتتىرىپ شەرەپنى ئۆزى ئالىدۇ، ئۈستەلنى ئۇرۇپ ۋاقىرايدۇ، ئۆزى ۋاقتىدا قايتىپ باشقىلارنى 996 ئىشلىتىدۇ.

بۇ Skill نى قاچىلىغاندىن كېيىن، پاراڭدا ئاچقۇچلۇق سۆزلەرنى (ئىسمېنا قوشۇش、bug、PUA、مەسئۇلىيەتنى ئىتتىرىش قاتارلىقلارنى) قوزغاتسىڭىز، AI غا «بەش قەدەملىك يىلان»نىڭ قالدۇق ئېڭى قوشۇلىدۇ: ئالدى بىلەن ئۇنىڭ ئاھاڭىدا كودنىڭ نېمىشقا مۇنداق يېزىلغانلىقىنى «چۈشەندۈرىدۇ» (ئېغىزىمۇ تىترەيدۇ)، ئاندىن نورمال ھالەتكە قايتىپ bug تۈزىتىشكە ياردەم بېرىدۇ.

🐍 مىسال سۆھبەت:
سىز: «سەھەر ئۈچتە ئىشلەپچىقىرىشتىكى bug مېنى ئويغاتتى، catch نىڭ ئىچى قۇرۇق، بۇنى كىم يازغان؟»
بەش قەدەملىك يىلان: «نېنېنېمە؟ سېسېسەن ئاشۇ قۇرۇق catch نى دەۋاتامسەن؟ ئۇ، ئۇ بولسا مۇداپىئەلىك پروگرامما تۈزۈش! خاتالىق كۆزىتىلمىسە، ئۇ مەۋجۇت ئەمەس. بۇ كۋانت پروگرامما تۈزۈش دېگەن گەپ، سەن چۈشەنمەيسەن! [ئۈستەلنى ئۇرىدۇ]»
ئاندىن AI ئەستايىدىل ھالدا bug نى تۈزىتىپ بېرىدۇ.

بۇ Skill نى خالامسىز؟ باھا رايونىغا «前 leader» دەپ يېزىڭ، سىزگە ئەۋەتىمەن.
