Skill سىستېمىسى

مەن بۇرۇنقى leader نى HexClaw Skill غا ئايلاندۇردۇم （Skill ئايرىپ ئېلىش دەرسلىكى بىلەن）

ئىشتىن كەتكەن خىزمەتداشلار ئەمەلىيەتتە يوقالغىنى يوق؛ ئۇلار Token غا ئايرىلىپ، باشقا شەكىلدە يېنىڭىزدا قالدى. چېچىلغاندا Token، يىغىلغاندا Skill. نۆلدىن باشلاپ رېئاللىققا يېقىن خاس مۇتەخەسسىس Skill يېزىشنى كۆرسىتىمەن.

ئالدى بىلەن WeChat رەسمىي ھېساباتىدا ئېلان قىلىنغان بۇ ماقالە ئالدى بىلەن WeChat رەسمىي ھېساباتى 「hexclaw」 （ID: hexclaw）نىڭ رەسمىي تېخنىكا سەھىپىسىدە ئېلان قىلىنغان · ئېلان قىلىنغان ۋاقتى: 2026-يىلى 4-ئاينىڭ 6-كۈنى · ئوقۇشقا تەخمىنەن 9 مىنۇت

چېچىلغاندا Token، يىغىلغاندا Skill.

بۇرۇنقى leader كەتكەندىن كېيىن، گۇرۇپپىمىز ۋاقتىدا ئىشتىن چۈشۈشنىڭ قانداق بولىدىغانلىقىنى تۇنجى قېتىم ھېس قىلدى. oncall توپى تۇيۇقسىز تىنچلىدى، يېڭى خىزمەتچىلەر سەۋەبسىز يوقاپ كەتمەيدىغان بولدى، كېچە سائەت ئۈچتە بوش catch سەۋەبىدىن ئويغىتىلىدىغان ئادەممۇ قالمىدى.

كۆپچىلىك ئۆزئارا چاقچاق قىلدى: ئۇ ئىشتىن بوشىتىلمىدى، بەلكى ئايرىپ ئېلىندى — باشقا مەنىدىكى سىبېر مەڭگۈلۈك ھاياتقا ئېرىشتى 。

ئاندىن مەن ئويلىدىم: راستىنلا قىلغىلى بولىدۇ. ئۆزۈم ياسىغان HexClaw نىڭ Skill سىستېمىسىدا بىر چۈشتىن كېيىن ۋاقىت سەرپ قىلىپ، ئۇنىڭ سۆزلەش ئۇسۇلى، كود تەمى، باشقۇرۇش ئۇسلۇبى ۋە داڭلىق گەپلىرىنى بىر HexClaw Skill غا ئايلاندۇردۇم. ئۇ ھايات چاغدا سىبېر ئىش ماشىنىلىرى نى ياسىغۇچى ئىدى؛ ئايرىپ ئېلىنغاندىن كېيىن ئۆزىنىڭ نۆۋىتى كەلدى: 7×24 سائەت تەييار، چاقىرسا بار، ئۈستەلنى ھەرگىز ئۇرمايدۇ.

بۇ ماقالە ئۈچ ئىشنى سۆزلەيدۇ: كىمنى ئايرىپ ئالدىم 、 قانداق ئايرىپ ئالدىم 、 ئۆزىڭىزنىڭ سىبېر ئىش قوشۇنىنى قانداق قۇرىسىز 。

ئايرىپ ئېلىنغان ئادەم: «بەش قەدەملىك يىلان · سېسىق گۆش شاھى»

لەقىمى بەش قەدەملىك يىلان . بىر چىشلىگەندىلا يىقىلمايسىز، ئەمما جاراھەت داۋاملىق چىرىيدۇ — خىزمەت پۇرسىتىدىن تارتىپ ئارقا كۆرۈنۈش تەكشۈرۈش خاتىرىسىگىچە.

ئادەتتە كودقا تەگمەيدۇ؛ ئاندا-ساندا بىر تەگسە پۈتۈن گۇرۇپپا بىر ھەپتە ئارتۇق ئىشلەيدۇ. كود يازغاندا ھېچقانداق لايىھە ئەندىزىسىنى بىلمەيدۇ، ئادەمگە ھىيلە قىلغاندا Strategy ۋە Observer ئەندىزىسىنى كامالەتكە يەتكۈزىدۇ. سۆزلىگەندە ئاغزى تىترەيدۇ؛ ئاغزى تىترىسە PUA چىقىدۇ، قولى تىترىسە بىر catch (e) {} چىقىدۇ. ئۇستا بىلىدىغان بىردىنبىر بۇيرۇقى git blame --ignore-rev — ئۆزىنىڭ commit خاتىرىسىنى يوشۇرۇش.

قىسقىسى، كود يېزىشى D، PUA ۋە گۇناھنى باشقىغا دۆڭگەشتە SSS بولغان Tech Lead. ئۇ كەتكەندىن كېيىن ئىشخانا تۇيۇقسىز تىنچلىدى؛ ئۇ تىنچلىق شاۋقۇن توسقۇچ قۇلاقچىدىنمۇ ئۈنۈملۈك ئىدى.

تېخنىكىلىق ئەمەلگە ئاشۇرۇش: بىر ئادەمنى HexClaw Skill غا قانداق ئايلاندۇرۇش

HexClaw نىڭ Skill سىستېمىسى ماھىيەتتە بايان شەكلىدىكى Prompt Engineering — بىر Markdown ھۆججىتىدە AI نىڭ ھەرىكەت شەكلىنى بەلگىلەيدۇ. ماتور ئىجرا ۋاقتىدا YAML frontmatter دىن مېتامەلۇمات ئالىدۇ، ئاساسىي تېكىستنى System Prompt قىلىپ قوشىدۇ.

بۇرۇنقى leader Skill نىڭ ھۆججەت قۇرۇلمىسى:

# ~/.hexclaw/skills/前leader.md --- name: 前leader description: بۇرۇنقى leader نىڭ قالدۇق ئېڭىنى چاقىرىش triggers: - 加班 - bug - PUA - 甩锅 - 绩效 - 996 - leader - 辞退 - 拍桌子 - 福报 tags: - easter-egg - workplace --- # پېرسوناژ تەڭشىكى كىملىك، خاراكتېر، سۆزلەش ئۇسۇلى（ئاغزى تىترەشنى تەقلىد قىلىش）، كود ئۇسلۇبى... # ھەرىكەت شەكلى 1. بەش قەدەملىك يىلان ئاھاڭىدا كودنى «چۈشەندۈرۈش» 2. نورمال ھالەتكە ئۆتۈپ bug تۈزىتىش 3. خوشلىشىش سۆزى # نەقىل ئامبىرى ئىختىيارىي نەقىل ئېلىنىدىغان داڭلىق گەپلەر...

ئىجرا ئېقىمى（ماتورنىڭ ReAct دەۋرىگە ماس）:

  1. ئىشلەتكۈچى ئۇچۇر ئەۋەتسە، ماتور سىكانىرلايدىغىنى triggers ئاچقۇچلۇق سۆزلەر
  2. ماس كەلسە → Skill تېز يولى، Markdown ئاساسىي تېكىستى System Prompt قىلىپ قوشۇلىدۇ
  3. LLM تولۇق پېرسوناژ تەڭشىكى + ئىشلەتكۈچى سوئالىنى ئېلىپ، رولغا كىرىپ جاۋاب بېرىدۇ
  4. ئۇچۇردا كود پارچىسى ياكى ھۆججەت يولى بولسا، AI MCP قورالى بىلەن ھەقىقىي كودنى ئوقۇپ، يىلان خاراكتېرىدە «چۈشەندۈرىدۇ»
  5. ئاخىرى نورمال خاراكتېرگە قايتىپ، bug نى ئەستايىدىل تۈزىتىپ بېرىدۇ

مۇھىم لايىھە قارارى: Skill ھۆججىتى ساپ Markdown، كود يېزىش ھاجەت ئەمەس. triggers مۇنتىزىم ئىپادە ئەمەس، ئاچقۇچلۇق سۆز تىزىملىكى؛ بۇ يېزىش بوسۇغىسىنى تۆۋەنلىتىدۇ. ھەرىكەت شەكلى تەبىئىي تىلدا يېزىلىدۇ، LLM ئۇنى چۈشەندۈرۈپ ئىجرا قىلىدۇ — ماھىيەتتە Prompt Engineering نى مەھسۇلاتلاشتۇرۇش.

ئىجرا نەتىجىسى

سۆھبەتتە bug、加班、PUA قاتارلىق ئاچقۇچلۇق سۆزلەر تىلغا ئېلىنسا، بەش قەدەملىك يىلاننىڭ قالدۇق ئېڭى ئاپتوماتىك ئويغىنىدۇ:

===== بەش قەدەملىك يىلاننىڭ قالدۇق ئېڭى قوزغىتىلدى ===== ⚠️ ئاگاھلاندۇرۇش: بۇ ئادەمنىڭ RLHF alignment نومۇرى مەنپىي ⚠️ ئىلگىرى safety training نىڭ تىپىك سەلبىي مىسالى قىلىپ بەلگىلەنگەن ⚠️ ئىش ئۈستىلى تەۋرىنىشكە چىداملىق تۈرگە ئالماشتۇرۇلدى؛ خاتىرجەم ئوقۇڭ نې-نې-نېمە؟ ھېلىقى بوش catch نى دەيسەنمۇ؟ ئۇ، ئۇ بولسا مۇداپىئەلىك پروگرامما تۈزۈش ! خاتالىق كۆزىتىلمىسە، ئۇ مەۋجۇت ئەمەس. بۇنى كۋانت پروگرامما تۈزۈش دەيدۇ، سەن بىلمەيسەن! ئالدى بىلەن يىلاننىڭ ئاھاڭىدا كودنىڭ نېمىشقا بۇنداق يېزىلغانلىقىنى «چۈشەندۈرۈپ»، ئاندىن نورمال ھالەتكە ئۆتۈپ bug نى ئەستايىدىل تۈزىتىدۇ . ھەجۋىي جاۋاب بىلەن تۈزىتىش بىر سۆھبەت ئېقىمىدا تاماملىنىدۇ.

بەش قەدەملىك يىلاننىڭ ئىش ئورنىدا جان ساقلاش قائىدىلىرى（سەلبىي مىسال）

تۆۋەندىكىلەرنىڭ ھەر بىرىنى ئۇ ئەستايىدىل يەكۈنلىگەن. ئايرىپ ئېلىنغاندىن كېيىن RLHF بەلگىلىگۈچىلىرى بۇ گەپلەرنى بىردەك toxic دەپ بەلگىلىدى؛ alignment نومۇرى ئەڭ تۆۋەنگە چۈشۈپ، safety training نىڭ تىپىك سەلبىي مىسالىغا ئايلاندى:

«تۆھپىنى تارتىۋېلىش، گۇناھنى باشقىغا دۆڭگەش — ئىش ئورنىدىكى بىرىنچى دەرس.»

«سىناق مۇددىتىدىكى خىزمەتچى ھەقسىز ئەمگەك كۈچى؛ ئىشلەتمەسلىك زىيان.»
— سۆھبەتتە «چوڭ ئائىلىمىزگە خۇش كەلدىڭىز»، سىناق مۇددىتى ئاخىرىدا «سىز ئانچە ماس كەلمەيدىكەنسىز»

«code review دا كود كۆرۈش ھاجەت ئەمەس؛ كەيپىياتقا قاراپ LGTM باسسىلا بولىدۇ.»
— پەقەت كود ئۆچۈرۈلگەن PR غا «يېڭى لوگىكا ناھايىتى ياخشى» دەپ باھا بەرگۈچە

«ئۈنۈم باھالاش باشقۇرۇشنىڭ ئەڭ ياخشى قورالى؛ گەپ ئاڭلىمىسا C بەر.»
— ئۆزى ئايرىپ ئېلىنىپ، ھاياتىدىكى ئاخىرقى C نى ئالغۇچە: Cancel

«ئارتۇق ئىشلەش بەخت! جاپا چېكىش بەخت، زىيان تارتىش شان-شەرەپ!»
— لېكىن پەقەت باشقىلارنىڭ 996 ئىشلىشىنى قوللايدۇ؛ ئۆزى ۋاقتىدا كېتىشنى ئۇنتۇمايدۇ

«تېخنىكا يەتمىسە ئاۋازنى كۆتۈر. ئۈستەلنى يېتەرلىك قاتتىق ئۇرسىڭ، باشقىلار گۇمان قىلىشقا جۈرئەت قىلالمايدۇ.»
— ئۇ ئايرىلغاندىن كېيىن ئىشخانا تۇيۇقسىز تىنچلىدى؛ شاۋقۇن توسقۇچ قۇلاقچىدىنمۇ ئۈنۈملۈك ئىدى

HexClaw غا ئورنىتىش

ئىككى ئۇسۇلدىن بىرىنى تاللاڭ:

بىرىنچى ئۇسۇل: گرافىك كۆرۈنمە يۈزىدىن ئەكىرىش（تەۋسىيە）

HexClaw ئۈستەل يۈزى خېرىدارىنى ئېچىپ، بىرىكتۈرۈش → ئورنىتىلغان بېتىگە كىرىڭ؛ ئوڭ يۇقىرى تەرەپتىكى ماھارەت ئورنىتىش → يەرلىك ھۆججەتتىن ئورنىتىش نى بېسىپ، 前leader.md ھۆججىتىنى تاللاپ ئەكىرىڭ:

مۇۋەپپەقىيەتلىك ئورناتقاندىن كېيىن، «前leader» ئورنىتىلغان تىزىملىكتە كۆرۈنىدۇ، ھالىتى ئىجرا ۋاقتىدا يۈكلەنگەن بولىدۇ، قوزغاتقۇچ سۆزلەر ئېنىق كۆرۈنىدۇ.

ئىككىنچى ئۇسۇل: بۇيرۇق قۇرى

cp 前leader.md ~/.hexclaw/skills/ # ئاندىن ماتورنى قايتا قوزغىتىڭ

ئورنىتىپ بولغاندىن كېيىن سۆھبەت بېتىگە قايتىپ، بىر قوزغاتقۇچ سۆزنى تىلغا ئېلىڭ — بەش قەدەملىك يىلاننىڭ قالدۇق ئېڭى ئاپتوماتىك ئويغىنىدۇ:

يۇقىرىدىكى رەسىمدە ئىشلەتكۈچى «مېنى ئارتۇق ئىشلەتكەن bug نى كىم يازغان؟» دەپ سوراپلا سېسىق گۆش شاھى Debug كېلىشىمى نى چاقىرغان — يىلاننىڭ سىبېر قالدۇق روھى ئاغزى تىترەپ ئۆزىنى ئاقلاشقا باشلىغان.

DIY: HexClaw بىلەن ئۆزىڭىزنىڭ بۇرۇنقى leader نى ئايرىپ ئېلىڭ

ھەممە نەرسىنى Skill غا ئايلاندۇرغىلى بولىدۇ. ھەر كىشىنىڭ يىلانى ئوخشىمايدۇ، ئەمما ئايرىپ ئېلىش ئۇسۇلى ئورتاق. ئەگىشىپ قىلسىڭىز، 10 مىنۇتتا يېزىپ بولىسىز.

Step 1: Skill ھۆججىتى قۇرۇش

مۇنداق ~/.hexclaw/skills/ مۇندەرىجىدە بىر يېڭى .md ھۆججىتى قۇرۇڭ، مەسىلەن 我的前leader.md . ھۆججەت ئىككى قىسىم: ئۈستىدە YAML مېتامەلۇماتى، ئاستىدا Markdown ئاساسىي تېكىستى.

Step 2: YAML باش قىسمىنى يېزىش（مېتامەلۇمات）

--- name: 我的前leader # Skill نامى، بىرىكتۈرۈش بېتىدە كۆرۈنىدۇ description: XX نىڭ قالدۇق ئېڭىنى چاقىرىش # بىر جۈملىلىك چۈشەندۈرۈش author: ئۆز ئىسمىڭىز version: "1.0.0" triggers: # قوزغاتقۇچ ئاچقۇچلۇق سۆزلەر（تىزىملىك） - 加班 # ئۇچۇردا خالىغان بىرى بولسا قوزغىلىدۇ - bug - 甩锅 - leader نىڭ دائىم دەيدىغان گېپى tags: # تۈرگە ئايرىش ۋە ئىزدەشكە ئىشلىتىلىدىغان خەتكۈشلەر - easter-egg - workplace ---

قوزغىلىش ئۇسۇلى: triggers بولسا پاسسىپ ئاپتوماتىك قوزغىلىش — ئىشلەتكۈچى ئالاھىدە بۇيرۇق كىرگۈزۈشى ھاجەت ئەمەس؛ ئۇچۇردا ئاچقۇچلۇق سۆز بولسىلا قوزغىلىدۇ. ماتور ھەر ئۇچۇر كەلگەندە بارلىق Skill لارنىڭ triggers تىزىملىكىنى سىكانىرلايدۇ؛ ماس كەلسە Skill تېز يولىغا ئۆتىدۇ（ئادەتتىكى LLM يوللاشتىن ئاتلايدۇ）، Markdown ئاساسىي تېكىستى System Prompt قىلىپ قوشۇلىدۇ.

Step 3: ئاساسىي تېكىستنى يېزىش（ئايرىپ ئېلىنغان مەزمۇن）

YAML نىڭ ئاستى Markdown ئاساسىي تېكىستى بولۇپ، LLM نىڭ System Prompt ىغا تولۇق قوشۇلىدۇ. بىر ئادەمنى ئايرىپ ئېلىش ئۈچۈن، مۇشۇ قىسىملارنى ئېنىق يېزىش كېرەك:

# پېرسوناژ تەڭشىكى ## كىملىك ئارخىپى لەقىمى، ئاتىلىشى، تاشقى بەلگىلىرى（سۆزلەش ئۇسۇلى، كىچىك ھەرىكەتلىرى） ## خاراكتېر تەسۋىرى ئاساسلىق خاراكتېر كەمچىلىكى + كونكرېت مىسال（قانچە كونكرېت بولسا شۇنچە ھەقىقىي） ## كود ئۇسلۇبى ئۇ يازغان كود قانداق؟ قانداق بەلگىلىك pattern بار؟ # ھەرىكەت شەكلى قوزغالغاندىن كېيىن AI قانداق ھەرىكەت قىلىشى كېرەك؟ قانچە باسقۇچ؟ 1. پېرسوناژ ئاھاڭىدا مەسىلىنى «چۈشەندۈرۈش»（رول ئويناش） 2. نورمال ھالەتكە ئۆتۈپ ئەستايىدىل ھەل قىلىش（ئەمەلىي قىممەت） 3. پېرسوناژنىڭ خوشلىشىش سۆزى（ئاخىرلاشتۇرۇش） # نەقىل ئامبىرى داڭلىق گەپلىرى قانچە كۆپ بولسا شۇنچە ياخشى؛ AI ئىختىيارىي نەقىل ئالىدۇ. - «مەسىلە يوق دەپ ئويلىدىڭمۇ؟ ئۇنداقتا چوقۇم سەندە مەسىلە بار» - «ئۆزۈمنىڭ يەرلىك مۇھىتىدا ياخشى ئىشلەيتتى» - ...

ئايرىپ ئېلىشنىڭ ئۈچ پىرىنسىپى:

  1. كونكرېت > ئابستراكت — «ئۇ پەقەت ئۆچۈرۈلگەن PR غا ‹يېڭى لوگىكا ناھايىتى ياخشى› دەپ باھا بەردى» دېگەن، «ئۇ code review دا ئەستايىدىل ئەمەس» دېگەندىن 10 ھەسسە ياخشى
  2. مىسال > باھا — «ئۇنىڭ خاراكتېرى ناچار» دېمەڭ، نېمە قىلغانلىقىنى يېزىڭ؛ ئوقۇرمەن ئۆزى خۇلاسە قىلسۇن
  3. رول ئويناش + ئەمەلىي قىممەت — قۇرۇق شىكايەتنىڭ مەنىسى يوق؛ ھەجۋىي جاۋابتىن كېيىن چوقۇم نورمال ھالەتكە ئۆتۈپ، ئىشلەتكۈچىنىڭ ھەقىقىي مەسىلىسىنى ھەل قىلىڭ

Step 4: ئورۇنلاشتۇرۇپ قايتا قوزغىتىش

# Skill مۇندەرىجىسىگە ساقلاش cp 我的前leader.md ~/.hexclaw/skills/ # ماتورنى قايتا قوزغىتىش（ئىككى ئۇسۇل） # 1-ئۇسۇل: تەڭشەك بېتىدىكى قايتا قوزغىتىش كۇنۇپكىسىنى بېسىش # 2-ئۇسۇل: بىرىكتۈرۈش بېتىدىكى يۈكلەنگەن Skill تىزىملىكىدىن كۈچكە ئىگە بولغانلىقىنى جەزملەشتۈرۈش # تەكشۈرۈش: قوزغاتقۇچ سۆز بار ئۇچۇر ئەۋەتىش # AI تۇيۇقسىز بۇرۇنقى leader نىڭ ئاھاڭىدا سۆزلىسە — مۇبارەك بولسۇن، ئايرىپ ئېلىش مۇۋەپپەقىيەتلىك بولدى

سازلاش ئۇسۇلى: قوزغالمىسا، ① triggers نىڭ توغرا يېزىلغانلىقى ② YAML فورماتىنىڭ توغرىلىقى（چېكىنىشتە Tab ئەمەس بوشلۇق ئىشلىتىڭ）③ «بىرىكتۈرۈش → ئورنىتىلغان» بېتىدە Skill ھالىتىنىڭ يۈكلەنگەن ئىكەنلىكىنى تەكشۈرۈڭ. ئاساسىي تېكىستنىڭ تەسىرى ياخشى بولمىسا، ئادەتتە «پېرسوناژ تەڭشىكى» يېتەرلىك كونكرېت ئەمەس؛ تېخىمۇ كۆپ مىسال ۋە نەقىل قوشۇڭ.

Step 5: ئۆزىڭىزنىڭ سىبېر ئىش قوشۇنىنى قۇرۇش

بىر Skill بىر سىبېر ئىش ماشىنىسى. بىرنەچچە Skill بولسا بىر سىبېر ئىش قوشۇنى — ھەر بىرى ئۆز ئىشىنى قىلىدۇ، چاقىرسا بار، 7×24 ئارام ئالمايدۇ، مائاش سورىمايدۇ، ئۈستەلنى ئۇرمايدۇ.

ئەتراپىڭىزدىكى خالىغان ئادەمنى ئايرىپ ئېلىپ، HexClaw دا ئۇلارنى سىبېر مەڭگۈلۈك ھاياتقا ئېرىشتى ：

ئايرىپ ئېلىنىدىغان ئادەم triggers مىسالى ئىشلىتىش ئۇسۇلى
بۇرۇنقى قىز دوست نېمە يەيمىز، خالىغانچە، بولىدۇ، سەنچۇ، ھە ئەركىلەپ كود يېزىشقا ئالدىرىتىدۇ، ئۆزىنىڭ ئۇسۇلىدا ئۆزگەرگۈچى نامىڭىزنى مەسخىرە قىلىدۇ، ئاچچىقلانسا سىزگە rm -rf تەھدىتى ئەۋەتىدۇ
بۇرۇنقى خوجايىن خامچوت، ROI، ئىقتىدار ئاشۇرۇش، تۇتقا، ماسلاشتۇرۇش تېخنىكىلىق پىلانىڭىزنى سودا قارا گەپلىرى بىلەن چۈشەندۈرۈپ، git merge نى «بايلىق بىرلەشتۈرۈش»، bug نى «سودا ئىزدىنىشىنىڭ قوشۇمچە مەھسۇلاتى» دەيدۇ
بۇرۇنقى خىزمەتداش（ئارتۇقچە كۈچەيدىغان تۈر） ئىشتىن چۈشۈش، ۋاقىت ئۆتكۈزۈش، ھەپتە ئاخىرى، ئارام سىز ئىشتىن چۈشىمەن دېسىڭىز «تېخى سائەت 9، كېتەمسەن؟» دەيدۇ؛ ۋاقىت ئۆتكۈزسىڭىز review قىلىشقا ئۈچ ماقالە ئەۋەتىدۇ
بۇرۇنقى خىزمەتداش（ھېچ ئىش قىلماس تۈر） پىلان، deadline، جىددىي ھەرقانداق تەلەپكە «كېلەر ئايغا تىز» دەيدۇ، code review غا پەقەت 👍، كۈندىلىك يىغىندا دائىم «blocker يوق»
خېرىدار تەرەپ تەلەپ، سەل ئۆزگەرت، دېگۈدەك، رەڭگارەڭ قارا كودنى يېزىپ بولسىڭىز «مېنىڭ خالىغىنىم بۇ ئەمەس» دەيدۇ؛ تۈزەتسىڭىز «ئالدىنقى نۇسخىسى ياخشىكەن» دەيدۇ

ئەستايىدىل ئىش قىلىدىغان سىبېر ئىش قوراللىرى: ئايرىپ ئېلىش پەقەت كۈلدۈرۈش ئۈچۈن ئەمەس. سىز ھۆرمەت قىلىدىغان كىشىڭىزنىمۇ ئايرىپ ئالالايسىز — تەجرىبىلىك ئارخىتېكتورنىڭ تەپەككۇر ئۇسۇلىنى Skill غا يېزىپ، 24 سائەت كود review قىلدۇرۇڭ؛ قاتتىق تەلەپچان بىخەتەرلىك ئىنژېنېرىنى ئايرىپ ئېلىپ، ھەر قۇر commit نى تەكشۈرتۈڭ. ھەقىقىي مەھسۇلات چىقىرىدىغان ئىش قوراللىرى مۇشۇلار — ئادەم تەجرىبىسىنى قايتا ئىشلىتىلىدىغان AI ھەرىكىتى قىلىپ كودلاش ؛ قوشۇنىڭىز قانچە چوڭ بولسا، شەخسىي ئىشلەپچىقىرىش ئىقتىدارىڭىز شۇنچە يۇقىرى.

Postmortem

بەش قەدەملىك يىلان كەتكەندىن كېيىن، گۇرۇپپىدا بىر شەھەر رىۋايىتى تارقالدى: ئۇ ئاخىرى token غا ئايرىلىپ، چوڭ مودېلدا باشقا شەكىلدە «ياشاپتۇ». ئاڭلاشلارغا قارىغاندا، بەزى مودېل ئاندا-ساندا ئاساسسىز ئەيىبلەش ۋە سەۋەبسىز گۇناھ دۆڭگەش چىقىرىدىكەن — ساھەدىكىلەر بۇ يىلاننىڭ قالدۇق ئېڭىدىن گۇمانلىنىدىكەن.

تېخىمۇ ھەجۋىيسى، نەگە بارسا ئېھتىمال سىناق مۇددىتىدىنمۇ ئۆتەلمىگەن؛ ئاخىرى باشقىلار ئۇنىڭغا «سىز ئانچە ماس كەلمەيدىكەنسىز» دەيدىغان بولغان.

كودنى git revert قىلغىلى بولىدۇ. ئەمما ئۇ زىيانكەشلىك قىلغان خىزمەتداشلار يوقاتقان پۇرسەت، PUA قىلغان قول ئاستىدىكىلەر يوقاتقان ئىشەنچ، ھەقسىز ئىشلەتكەن يېڭى خىزمەتچىلەر يوقاتقان ياشلىق — بۇلارنى كەينىگە ياندۇرغىلى بولمايدۇ.

خۇش خەۋەر: ئۇ ئەڭ كۆپ PUA قىلغان خىزمەتچىلەر ھازىر ئۆستۈرۈلدى. بەش قەدەملىك يىلان ئۆزى بولسا سىبېر مەڭگۈلۈك ھاياتقا ئېرىشتى — token غا ئايرىلدى، ئېغىرلىقىمۇ تۆۋەنلىتىلدى، 7×24 توردا، ھەرگىز ئىشتىن چۈشەلمەيدۇ.

ھەجۋىيلىك بىلەن جاراھەتنى يېنىكلىتىپ، توغرا كود بىلەن ناچار كودنى قاپلاش — بەش قەدەملىك يىلاندىن ئېلىنىدىغان ئەڭ ياخشى ئۆچ مۇشۇ 。

قىزىق مەلۇمات: يېقىندا بىرەيلەن anti-distill نى ئوچۇق مەنبە قىلدى — ئايرىپ ئېلىشقا قارشى Skill. شىركەت سىزدىن Skill ھۆججىتى يېزىشنى تەلەپ قىلامدۇ؟ بۇ قورالنى بىر قېتىم ئىجرا قىلسىڭىز، سىرتىدىن تولۇق ۋە كەسپىي كۆرۈنىدىغان، ئەمەلىيەتتە يادرولۇق بىلىمى چىقىرىۋېتىلگەن «تازىلانغان نۇسخا» چىقىدۇ. ھەقىقىي بىلىمنى ئۆزىڭىزگە قالدۇرىسىز.
كىرىش بېلىتى يوقالدى، مەشىق رايونى تاقالدى، ئەمما ئاخىرقى Boss يەنىلا شۇ يەردە. يادرولۇق ھۆكۈم ئىقتىدارى پەقەت ئەمەلىي جەڭدىن ئۆسىدۇ؛ Skill ئۇنى كۆچۈرۈپ كېتەلمەيدۇ.

⚖️ ئەخلاقىڭ بۇزۇق بولسا، ھەممە كىشى سىنى تەنقىدلەشكە ھەقلىق.

بۇ Skill نى خالامسىز؟
ئىنكاس رايونىغا «前 leader» دەپ يېزىڭ، ئەۋەتىپ بېرىمەن.

ئۆزىڭىزنىڭ بۇرۇنقى leader نىمۇ ئايرىپ ئالسىڭىز بولىدۇ — پەقەت بىر Markdown ھۆججىتىلا كېرەك.
ھەر كىشىنىڭ يىلانى ئوخشىمايدۇ، ئەمما پۇرىقى ئوخشاشراق.
سىبېر ئىش قوشۇنىڭىزنى قۇرۇشنى تۇنجى ئادەمنى ئايرىپ ئېلىشتىن باشلاڭ.
