مەنبە ئىزدەش ۋە ئەستە تۇتۇش

كىرگۈزۈلگەن ماتېرىيال ۋە مەنبەنى ئىزدەڭ؛ ئۇزاق مۇددەتلىك ئەستە تۇتۇشنى كۆرۈڭ، تۈزىتىڭ ياكى ئۆچۈرۈڭ.

ۋەزىپىگە ماس مەخسۇس Agent

Agent نىڭ رولى ۋە ئەسكەرتىش قېلىپىنى قۇرۇڭ؛ K12 مەخسۇس يېتەكچىلىكى سىنارىيەلەرنىڭ بىرى.

ھۆججەت ۋە كۆپ ۋاسىتە نەتىجىسى

ھۆججەت، رەسىم ۋە ئاۋاز ھاسىل قىلىڭ؛ نەتىجە تاختىسىدا ئالدىن كۆرۈش ۋە تەھرىرلەشنى قوللايدۇ.

ئاپتوماتلاشتۇرۇش ۋە پىلانلاش

پىلان ياكى Webhook ئارقىلىق ۋەزىپە باشلاپ، جەرياننى كۆرۈڭ؛ قايتا سىناش ۋە بىكار قىلىشنى قوللايدۇ.

ئۈچ قەدەمدە ئىشلىتىشنى باشلاڭ

ئەپنى ئورنىتىپ مۇلازىمەت ۋە مودېلغا ئۇلاڭ، ئاندىن تونۇش بىر ۋەزىپىنى سىناڭ.
1

چۈشۈرۈپ ئورنىتىش

macOS تا بىر قۇر بۇيرۇق بىلەن ئورنىتىش تەۋسىيە قىلىنىدۇ؛ ياكى سىستېمىغا ماس قاچىلاش بولىقىنى چۈشۈرۈڭ.
2

مۇلازىمەت ۋە مودېلغا ئۇلىنىش

يەرلىك ياكى ئۆزىڭىز ئورۇنلاشتۇرغان مۇلازىمەتنى تاللاپ، مودېلنى جەزملەشتۈرۈڭ؛ قوراللارنى ۋەزىپىگە قاراپ ئۇلاڭ.
3

ئېنىق بىر ۋەزىپىنى سىناش

ئۇچۇر ياكى ماتېرىيال ئەۋەتىپ، جەريان ۋە نەتىجە ھۆججىتىنى كۆرۈڭ. مەخسۇس رول كېرەك بولسا Agent قۇرۇڭ.

چۈشۈرۈش ۋە ئورنىتىش

يۇمشاق دېتال ھەقسىز ۋە ئوچۇق مەنبەلىك. تور مودېللىرى ۋە سىرتقى مۇلازىمەتلەرنىڭ ھەققى ئايرىم ھېسابلىنىدۇ.

سىستېما تەلىپى ۋە ئورنىتىش قوللانمىسى

macOS بىر قۇر بۇيرۇق بىلەن ئورنىتىش (تەۋسىيە)

بۇيرۇقنى Terminal غا كۆچۈرۈپ ئىجرا قىلىڭ. ھازىرقى زاپچاسلارغا macOS 14 ياكى يېڭىراق نۇسخا كېرەك؛ Apple Silicon ۋە Intel قوللىنىدۇ.

curl -fsSL https://raw.githubusercontent.com/hexagon-codes/hexclaw-desktop/80060ab08b60b92b6cac4aa552a046b8e467c2b3/install.sh | bash

ئەڭ يېڭى ئاشكارا نۇسخا ئورنىتىلىدۇ؛ ئالدىن ئېلان قىلىنغان نۇسخا بولۇشى مۇمكىن.

ياكى Homebrew ئارقىلىق ئورنىتىڭ:

brew tap hexagon-codes/tap && brew install --cask hexclaw
