ئالىي ئىقتىدارلار

MCP، بىلىم ئامبىرى ۋە ئەستە تۇتۇش، ئاپتوماتلاشتۇرۇش، ئۇلىنىش مەركىزى، Skill ۋە بىخەتەرلىك.

ئىشلەتكىلى بولىدىغان ئىقتىدارلار قاچىلانغان نەشر، ئۇلانغان مۇلازىمەت ۋە قوزغىتىلغان ئىقتىدارلارغا باغلىق. سۈرەتلەر كىرىش ئورنىنى چۈشەندۈرۈش ئۈچۈن بېرىلگەن.

سۆھبەتتە بايلىقلارنى باشقۇرۇش

Agent تىن بايلىق تىزىملىكىنى سوراش، بايلىق قۇرۇش، ئورنىتىش، ئۆزگەرتىش، قوزغىتىش ۋە ئىجرا قىلىشنى تەلەپ قىلالايسىز. مەشغۇلات نۆۋەتتىكى ھوقۇق ۋە تەڭشەكلەرگە ئەگىشىدۇ؛ ھالەت ئەمەلىي نەتىجىگە ئاساسەن كۆرسىتىلىدۇ.

سۆھبەتتىكى تەلەپتاماملىنىدىغان ئىش
«قايسى MCP لار ئۇلانغان؟ قانداق Skill ۋە Agent لىرىم بار؟»بايلىق، ئۇلىنىش ھالىتى ۋە تەپسىلاتىنى كۆرۈش؛ Prompt، ئەستە تۇتۇش، بىلىم مەزمۇنى ۋە سۆھبەت تارىخىنى ئىزدەش.
«بۇ تېكىستنى بىلىم ئامبىرىغا قوش.»تېكىستنى ساقلاپ بىر تەرەپ قىلىش؛ ئىزدەشكە تەييار بولۇش ھالىتىنى ئەمەلىي ئىندېكس نەتىجىسىدىن كۆرۈش.
«بۇ مايىللىقىمنى ئەستە تۇت، كونا ئۇچۇرنى ئۆزگەرت.»ئۇزۇن مۇددەتلىك ئەستە تۇتۇشنى قوشۇش، يېڭىلاش، ئۆچۈرۈش ياكى مۇقىملاش.
«بۇ ئۇسۇلنى Skill قىلىپ ساقلا ۋە قوزغات.»Skill قۇرۇش ياكى ئۆزگەرتىش، ساقلاش، ئاكتىپلاش ۋە يۈكلەش؛ تەييار Skill ياكى MCP نى ئىزدەپ ئورنىتىش.
«بۇ Prompt نى ساقلا؛ بۇ قېلىپتىن ياردەمچى قۇر.»Prompt قۇرۇش، ئۆزگەرتىش ۋە قوزغىتىش ياكى توختىتىش؛ قېلىپ ياكى بېرىلگەن تەڭشەك بىلەن Agent قۇرۇش ۋە يېڭىلاش.
«ھەر كۈنى سائەت توققۇزدا ماتېرىيال رەتلە؛ ھازىر بىر قېتىم ئىجرا قىل.»ۋاقىتلىق ۋەزىپە قۇرۇش ياكى ئۆزگەرتىش، تىزىملاش، ۋاقىتلىق توختىتىش، ئەسلىگە كەلتۈرۈش ۋە ئۆچۈرۈش؛ ئېنىق تەلەپ قىلىنغاندا دەرھال ئىجرا قىلىش.
«بۇ باسقۇچلارنى ئىش ئېقىمى قىلىپ ساقلا، ئاندىن ئىجرا قىل.»ئىش ئېقىمى قۇرۇش ياكى ئۆزگەرتىش، ئېنىق تەلەپ بويىچە ئىجرا قىلىش ۋە نەتىجىنى كۆرۈش؛ Webhook باغلىنىشى ۋە قوزغىتىش ھالىتىنى باشقۇرۇش.

سۆھبەت بىلەن باشقۇرۇش بېتى بىر بايلىقنى ئىشلىتىدۇ. پەقەت سۈرۈشتۈرۈش ئىجرا قىلىشنى باشلىمايدۇ؛ پەقەت دەسلەپكى نۇسخا تەلەپ قىلىنسا ئۇ قوزغىتىلمايدۇ. ساقلاش، يۈكلەش، ئۇلىنىش، ئىجرا ۋە يەتكۈزۈش ھالىتى ئايرىم كۆرسىتىلىدۇ.

MCP قوراللىرى

سۆھبەتتە ئۇلانغان MCP مۇلازىمىتى ۋە قوراللىرىنى سۈرۈشتۈرۈش، تەييار مۇلازىمەتنى ئىزدەپ ئورنىتىشقا بولىدۇ. سىرتقى مۇلازىمەت ئۈچۈن مۇناسىۋەتلىك ھېسابات، ئۇلىنىش ۋە ھوقۇق لازىم.

Model Context Protocol ئارقىلىق ھۆججەت سىستېمىسى، ساندان، API ۋە باشقا سىرتقى قوراللارنى Agent قا ئۇلايسىز. ھەر بىر MCP مۇلازىمېتىرنىڭ ھوقۇقىنى ئېھتىياجغا قاراپ چەكلەڭ.

Filesystem MCP مىسالى

MCP قوشقاندا stdio نى تاللاپ، تۆۋەندىكى command ۋە args نى تولدۇرۇڭ. /path/to/your/projects نى ئەمەلىي مۇندەرىجە بىلەن ئالماشتۇرۇڭ. مۇلازىمەت ئىجرا بولغان ماشىنىدا Node.js ۋە npm بولۇشى كېرەك؛ بۇلۇتقا ئۇلانغاندا بۇ مۇندەرىجە بۇلۇت ماشىنىسىغا تەۋە.

{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem@2026.7.10", "/path/to/your/projects"]
    }
  }
}

بىلىم ئامبىرى

PDF، Word، Markdown ۋە باشقا ھۆججەتلەرنى بىلىم ئامبىرىغا قوشۇپ، RAG ئارقىلىق سۆھبەت ياكى Agent ۋەزىپىلىرىدە ئىشلىتىشكە بولىدۇ. سانلىق مەلۇمات نۆۋەتتە ئۇلانغان يەرلىك ياكى بۇلۇت مۇلازىمىتىدە ساقلىنىدۇ.

يۈكلەشنىڭ مۇۋەپپەقىيەتلىك بولۇشى، ئەسلى ھۆججەتنىڭ ساقلىنىشى ۋە ئىزدەشكە تەييار بولۇشى ئايرىم ھالەت. بىر تەرەپ قىلىش ۋە ئىندېكس ئىلگىرىلىشىنى كۆرۈڭ؛ ئۈزۈلۈش ياكى خاتالىق بولسا ۋەزىپىدىكى ئەسلىگە كەلتۈرۈش مەشغۇلاتىنى ئىشلىتىڭ. سۆھبەتتىكى تېكىستنىمۇ Agent ئارقىلىق قوشقىلى بولىدۇ.

ئەستە تۇتۇش

مۇھىم پاكىت، مايىللىق ۋە ئۇزۇن مۇددەتلىك مەزمۇن كېيىنكى سۆھبەتلەردە ئىشلىتىلىدۇ. ئاپتوماتىك ساقلاش نۆۋەتتىكى تەڭشەككە ئەگىشىدۇ؛ سۆھبەتتە ئېنىق تەلەپ قىلىپ ئۇچۇر قوشۇش، تۈزىتىش، ئۆچۈرۈش، مۇقىملاش ياكى مۇقىملاشنى بىكار قىلىشقا بولىدۇ.

ۋاقىتلىق ۋەزىپە

Cron شەكلىدىكى ۋاقىت بەلگىلىمىسى بىلەن Agent ۋەزىپىسىنى ئاپتوماتىك ئىجرا قىلىڭ. سۆھبەتتە ۋاقىت ۋە ۋەزىپىنى ئېيتىپ قۇرۇش ياكى ئۆزگەرتىش، تىزىملاش، توختىتىش، ئەسلىگە كەلتۈرۈش ۋە ئۆچۈرۈشكە بولىدۇ. ئېنىق تەلەپ قىلىنغاندا دەرھال ئىجرا قىلىنىدۇ؛ پىلان قۇرۇش قوشۇمچە بىر قېتىم ئىجرا قىلىشنى بىلدۈرمەيدۇ.

نەتىجە تەڭشەلگەن نىشانغا يەتكۈزۈلىدۇ. ئىجرا ۋە يەتكۈزۈش ھالىتىنى ئايرىم كۆرۈڭ؛ كۆپ باسقۇچلۇق ۋەزىپە ئۈچۈن ئىش ئېقىمى ئىشلىتىڭ.

كىرىش Webhook قوزغاتقۇچلىرى

ئاپتوماتلاشتۇرۇش → Webhooks دىن سىرتقى ۋەقەگە باغلانغان ۋەزىپە، Prompt ياكى Agent نى قوزغىتىڭ. HMAC-SHA256 ئىمزا، ۋاقىت ۋە nonce تەكشۈرۈلىدۇ؛ تەكرار ۋەقە ئەسلى receipt نى قايتۇرىدۇ. ۋەقە خاتىرىسى، خاتالىق ۋە قايتا سىناش ھالىتىنى ئايرىم كۆرۈڭ.

Skill بازىرى

Skill لار ۋەزىپىگە ماس Prompt، قورال ۋە ئىجرا قائىدىلىرىنى ئۆز ئىچىگە ئالىدۇ. سۆھبەتتە مەۋجۇت Skill نى ئىزدەش، ئورنىتىش، تىزىملاش ۋە چىقىرىۋېتىش، ئۆز Skill ىڭىزنى قۇرۇش ياكى ئۆزگەرتىشكە بولىدۇ.

«ساقلاپ قوزغات» دېگەن تەلەپ بويىچە Agent نۆۋەتتىكى ھوقۇق دائىرىسىدە ساقلاش، ئاكتىپلاش ۋە يۈكلەشنى تاماملايدۇ. پەقەت دەسلەپكى نۇسخا تەلەپ قىلىنسا شۇ نۇسخىلا ساقلىنىدۇ. ئورنىتىلغان، قوزغىتىلغان ۋە چاقىرىشقا تەييار ھالەت ئايرىم كۆرسىتىلىدۇ.

Prompt ئامبىرى

قايتا ئىشلىتىلىدىغان Prompt لارنى باشقۇرۇش بېتىدە ياكى سۆھبەتتە سۈرۈشتۈرۈش، قۇرۇش، ئۆزگەرتىش، قوزغىتىش ۋە توختىتىشقا بولىدۇ. ئۆزگەرتىش تەلەپ قىلىنمىغان مودېل، قورال دائىرىسى ۋە ھالەت ساقلىنىدۇ.

ئۇلىنىش مەركىزى

ئۇلىنىش بېتىدە Feishu، DingTalk، WeCom، WeChat، Slack، Discord ۋە Telegram قاتارلىق IM ھېساباتلىرىنى باشقۇرىسىز. نۆۋەتتىكى main مۇلازىمىتى قوزغىتىلغان ھېسابات ساقلانغاندا ئۇنى باشلايدۇ ياكى قايتا ئۇلايدۇ. ھېسابات ھالىتى ۋە خاتالىقنى كۆرۈڭ؛ ئۇلىنىش مۇۋەپپەقىيىتى ئۇچۇرنىڭ يەتكۈزۈلگەنلىكىنى بىلدۈرمەيدۇ. كونا قاچىلانغان نەشر قايتا قوزغىتىشنى تەلەپ قىلسا، شۇ كۆرسەتمىگە ئەگىشىڭ.

ساندان ئۇلىغۇچلىرى (MySQL / Redis)

ئۇلىنىش بېتىدىكى سانلىق مەلۇمات ئۇلىغۇچلىرىدىن تۈر، ئادرېس، ساندان ۋە ھالەتنى كۆرۈڭ. ئۇلىنىشنى سىناپ بولغاندىن كېيىن ماس MCP قورالى بىلەن ئىشلىتىڭ؛ سەپلەنمىگەن تۈرلەرنى ئاۋۋال تولۇقلاڭ.

مودېل تەپەككۇرى ۋە ماتېرىيال ئىزدەش

سۆھبەت رامكىسىنىڭ ئاستىنقى قورال بالداقتىن مودېل ۋە ئۇ قوللايدىغان تەپەككۇر تاللانمىسىنى تەڭشەڭ؛ ئايرىم سۆھبەت ھالىتىگە ئالماشتۇرۇش ھاجەتسىز. مودېل تەپەككۇر مەزمۇنى قايتۇرغاندىلا ئۇ كۆرسىتىلىدۇ. تەپەككۇرنى ئېچىش تور ئىزدەشنى ئاپتوماتىك ئاچمايدۇ؛ ئەمەلىي قورال چاقىرىشى، مەنبە ۋە ئاخىرقى نەتىجىنى تەكشۈرۈڭ.

بىخەتەرلىك تەكلىپى

  • API Key نى ئوچۇق ئامبارغا يوللىماڭ.
  • MCP قوراللىرىغا ئەڭ كىچىك ھوقۇقلا بېرىڭ.
  • ھۆججەت ياكى كود ئىجرا قىلىش قوراللىرىدا workspace چەكلىمىسىنى ساقلاڭ.
  • تورسىز ئىشلىتىش ئۈچۈن مودېلدىن باشقا قورال ۋە مۇلازىمەتلەرنىڭمۇ تور تەلەپ قىلمايدىغانلىقىنى تەكشۈرۈڭ.
