كۆپ كۆرۈلىدىغان سوئاللار

ئورنىتىش، ئۇلىنىش، يەرلىك مودېل، سانلىق-مەلۇمات ۋە ئىشلىتىشتىكى كۆپ كۆرۈلىدىغان مەسىلىلەر.

ئورنىتىش ۋە قوزغىتىش

ئەپ ئېچىلماي ياكى مۇلازىمەتكە ئۇلانماي قالسا؟

كۆرۈنمە يۈز يۈكلەنمىگەنلىكى بىلەن مۇلازىمەت ئۇلانمىغانلىقىنى ئايرىڭ. خاتىرىنى كۆرۈڭ. يەرلىك ھالەتتە Sidecar ۋە 16060 ئېغىزىنى؛ بۇلۇتتا ئادرېس، زىيارەت token ۋە مۇلازىمېتىر ھالىتىنى تەكشۈرۈڭ. ئۈستەلئۈستى ئەپنى قايتا قوزغىتىش بۇلۇت مۇلازىمىتىنى قايتا قوزغاتمايدۇ.

مودېل ۋە API

API تەلىپى 401 ياكى 403 قايتۇرسا؟

تەڭشەكتىكى مودېل تەمىنلىگۈچىدىن نۆۋەتتىكى Provider، ئادرېس، ئاچقۇچ ۋە مودېل زىيارەت ھوقۇقىنى تەكشۈرۈڭ. كونكرېت خاتالىققا قاراڭ؛ ھالەت كودىلا ھېسابات قالدۇقى يوقلۇقىنى ئىسپاتلىمايدۇ.

API Key قەيەردە ساقلىنىدۇ؟

يەرلىك Provider سەپلىمىسى ۋە API Key ~/.hexclaw/hexclaw.yaml دا ساقلىنىدۇ، مەشغۇلات سىستېمىسىنىڭ ئاچقۇچ ساقلاش مۇلازىمىتىدە ئەمەس. بۇلۇت مۇلازىمىتى مۇلازىمېتىردىكى ئۆز سەپلىمىسىنى ئىشلىتىدۇ.

Ollama نى قانداق ئىشلىتىمەن؟

نۆۋەتتىكى HexClaw مۇلازىمىتى Ollama ۋە چۈشۈرۈلگەن مودېلغا ئۇلىنالايدىغان بولسۇن. macOS بولىقى Ollama نى ئۆز ئىچىگە ئالىدۇ؛ Windows / Linux دا يەرلىك مودېل ئۈچۈن ئايرىم ئورنىتىش كېرەك. ماس ئادرېس ۋە ئەمەلىي چۈشۈرۈلگەن مودېل نامىنى تولدۇرۇڭ؛ API Key بوش قالىدۇ.

localhost HexClaw مۇلازىمىتى ئىجرا بولۇۋاتقان ماشىنا؛ بۇلۇتقا ئۇلانغاندا ئۈستەلئۈستى كومپيۇتېرىڭىز ئەمەس. يەرلىك مودېل تور ئىزدەش ياكى سىرتقى قوراللارنى تورسىز قىلىپ قويمايدۇ.

جاۋاب ئېقىمى توختاپ قالسا؟

ۋەزىپە ئىلگىرىلىشى، قورال پائالىيىتى ۋە خاتىرىنى كۆرۈپ، تېخى ئىشلەۋاتقان مودېل، ئۈزۈلگەن ئۇلىنىش ۋە ئېنىق مەغلۇبىيەتنى ئايرىڭ. تەلەپنى توختاتقىلى بولىدۇ؛ قوللايدىغان ۋەزىپە ئەسلى تەلەپتىن داۋاملىشىدۇ. نەتىجە نامەلۇم بولسا، ھەق ياكى سىرتقى تەسىر پەيدا قىلىدىغان مەشغۇلاتنى قايتا ئەۋەتىشتىن بۇرۇن ئەسلى ۋەزىپە ۋە بار ھۆججەتنى تەكشۈرۈڭ.

سانلىق-مەلۇمات ۋە مەخپىيەتلىك

ئۇچۇرلىرىم قەيەردە؟

كۆرۈشۈش، ئۆگىنىش خاتىرىسى، بىلىم ۋە ھاسىل قىلىنغان ھۆججەتلەر تاللانغان مۇلازىمەتتە ساقلىنىدۇ: يەرلىكتە بۇ ئۈسكۈنىدە، بۇلۇتتا مۇلازىمېتىردا. كۆرۈنۈش قاتارلىق ئۈستەلئۈستى مايىللىقلىرى ئايرىم باشقۇرۇلىدۇ. مۇلازىمەت ئالماشتۇرۇش سانلىق-مەلۇمات، مودېل سەپلىمىسى ۋە ئۇلىنىشلارنى ئاپتوماتىك كۆچۈرمەيدۇ ياكى بىرلەشتۈرمەيدۇ.

سانلىق-مەلۇمات ئۈچىنچى تەرەپكە ئەۋەتىلەمدۇ؟

تور مودېلى ۋەزىپىگە كېرەكلىك سوئال، رەسىم، ھۆججەت مەزمۇنى ۋە مەزمۇن مۇھىتىنى قوبۇل قىلىدۇ. تور ئىزدەش، MCP ۋە ئۇچۇر قاناللىرىمۇ ئۆز مەشغۇلاتىغا كېرەكلىك مەزمۇننى ئالىدۇ. Ollama يەرلىك مۇلاھىزە قىلالايدۇ؛ پۈتۈن ۋەزىپىنىڭ تورسىز بولۇشى قورال ۋە مۇلازىمەتكە باغلىق.

ئىجرا قىلىش ۋە قوراللار

MCP ئۇلانمىسا؟

مۇلازىمېتىر جەريانىنى، stdio، sse ياكى streamable_http تۈرىنىڭ ماسلىقىنى تەكشۈرۈڭ. تولۇق خاتالىقنى خاتىرە بېتىدىن كۆرۈڭ.

ئىش ئېقىمى مەغلۇپ بولسا؟

مەغلۇپ تۈگۈننىڭ خاتالىقىنى كۆرۈپ، مودېل سەپلىمىسى، قورال ئۇلىنىشى ۋە تەلەپ چېكىنى تەكشۈرۈڭ. سىرتقى مەشغۇلات نەتىجىسى نامەلۇم بولسا، ئەسلى ئىجرا خاتىرىسىنى تەكشۈرۈپ ئاندىن كېيىنكى قەدەمنى قارار قىلىڭ.

كۆپ Agent نى قانداق تاللايمەن؟

قاتنىشىش نۆۋەتتىكى مۇلازىمەت ۋە سەپلەنگەن Agent لارغا باغلىق. مەسئۇلىيىتى ئېنىق روللارنى تاللاڭ؛ كۆپ قاتناشقۇچى تېخىمۇ كۆپ مەزمۇن ۋە مودېل چاقىرىشىنى تەلەپ قىلىدۇ، ياخشى نەتىجىگە كاپالەت بەرمەيدۇ.

چوڭقۇر ئويلىنىش

ئويلىنىشنى ئاچسام تور ئىزدەمدۇ؟

ئويلىنىش تەڭشىكى مودېل قوللايدىغان مۇلاھىزىنى كونترول قىلىدۇ. تور ئىزدەشكە قورال ۋە ئەمەلىي چاقىرىش كېرەك. پائالىيەت ۋە مەنبەلەرنى كۆرۈپ، مۇلاھىزە بىلەن ئىزدەش نەتىجىسىنى ئايرىڭ.

نەتىجە يېتەرلىك بولمىسا؟

ۋەزىپىگە ماس مودېل تاللاڭ، تېما ۋە دائىرىنى ئېنىقلاڭ، لازىملىق چىقىرىش شەكلى ۋە مەنبە تەلىپىنى يېزىڭ.

ئۇلىنىش ۋە ئۇچۇر قاناللىرى

قانال سەپلەنگەن بولسىمۇ ئۇچۇر كەلمىسە؟

ئۇلىنىش بېتىدە ھالەت، ئاچقۇچ، قوبۇل قىلىش ھوقۇقى ۋە نىشان سۆھبەت باغلىنىشىنى تەكشۈرۈڭ. K12 باغلانغان ئاتا-ئانا بىلەن ماشىنا ئادەم ئوتتۇرىسىدىكى يەككە سۆھبەتنى ئىشلىتىدۇ. قانالنىڭ قايتا ئۇلىنىش ئەسكەرتمىسى ۋە خاتالىق خاتىرىسىگە قاراڭ.

ماھارەت بازىرى

ClawHub دىن ئورنىتىلغان Skill ئىشلىمىسە؟

بازار نۆۋەتتىكى مۇلازىمەت ئارقىلىق ئىزدەيدۇ ۋە ئورنىتىدۇ. ئىقتىدار → Skills دا ئورنىتىلغان ۋە قوزغىتىلغانلىقىنى، ئاندىن Agent سەپلىمىسى، تايىنىشلىرى ۋە ئىجرا خاتىرىسىنى تەكشۈرۈڭ. بازاردا كۆرۈنۈش ئورنىتىش مۇۋەپپەقىيىتى ئەمەس. يەرلىك ھۆججەت ياكى URL دىنمۇ ئورنىتىشقا بولىدۇ.

ئىقتىدار ۋە ھالەت

ئىچكى ساقلىغۇچ كۆپ ئىشلىتىلسە؟

WebView، HexClaw مۇلازىمىتى ۋە يەرلىك مودېل جەريانىنى ئايرىڭ. ئۇزۇن سۆھبەت، مېدىيا، ھۆججەت بىر تەرەپ قىلىش ۋە مودېل چوڭلۇقى تەسىر كۆرسىتىدۇ. كېرەكسىز ئالدىن كۆرۈشنى تاقاپ، ۋەزىپە ۋە مودېل جەريانىنى تەكشۈرۈڭ. ۋەزىپە تۈگىگەندىن كېيىنمۇ نورمال بولمىسا، خاتىرىنى ساقلاپ مۇناسىۋەتلىك ئەپ ياكى مۇلازىمەتنى قايتا قوزغىتىڭ.

مۇلازىمەت ھالىتىنى قەيەردىن كۆرىمەن؟

تەڭشەكتىكى مۇلازىمەت كارتىسىدا يەرلىك ياكى بۇلۇت ئۇلىنىشىنى، خاتىرىدە ئىجرا تەپسىلاتىنى كۆرۈڭ. ھەققىدە بېتى ئۈستەلئۈستى، ئارقا سۇپا ۋە زاپچاس نۇسخىسىنى كۆرسىتىدۇ. ئۇلانغان ھالەت ۋەزىپە ياكى ئەۋەتىش تاماملاندى دېگەنلىك ئەمەس.

مەھسۇلات تاللاش

HexClaw يەرلىك ياكى ئۆزىڭىز قۇرغان بۇلۇت مۇلازىمىتىگە ئۇلىنىدىغان ئوچۇق كودلۇق Agent سۇپىسى؛ كۆپ مودېل، بىلىم، MCP، Skill ۋە ئاپتوماتلاشتۇرۇشنى بىرلەشتۈرىدۇ. ۋەزىپە، ئورۇنلاشتۇرۇش ۋە قورال ئېھتىياجىڭىز بويىچە سېلىشتۇرۇڭ. باشقا مەھسۇلاتلارنىڭ ئىقتىدارى ۋە شەرتىنى نۆۋەتتىكى رەسمىي ھۆججىتىدىن كۆرۈڭ.

زاپاسلاش ۋە بىلىم ئامبىرى

سانلىق-مەلۇماتنى قانداق زاپاسلايمەن ياكى كۆچۈرىمەن؟

يەرلىك ياكى بۇلۇت مۇلازىمىتىگە تەۋە ئىكەنلىكىنى جەزملەشتۈرۈڭ. تولۇق زاپاس ئەمەلىي ساندان، ماتېرىيال ۋە نەتىجە مۇندەرىجىسى، سەپلىمىنى قاپلىشى كېرەك؛ شۇ ئورۇنلاشتۇرۇشنىڭ زاپاسلاش ئۇسۇلىنى ئىشلىتىڭ. ئۈستەلئۈستى مايىللىقلىرى سودا سانلىق-مەلۇمات زاپىسى ئەمەس. سۆھبەتنى چىقارغىلى، ئائىلە ئۆگىنىش ئارخىپىنى .hexbak شەكلىدە ساقلاپ ئەسلىگە كەلتۈرگىلى بولىدۇ. مۇلازىمەت ئالماشتۇرۇش سانلىق-مەلۇماتنى كۆچۈرمەيدۇ؛ ئاچقۇچ ۋە سەپلىمىنى ئايرىم مۇۋاپىق ساقلاڭ.

قانچىلىك چوڭ ھۆججەت قوللىنىدۇ؟

نۆۋەتتىكى مۇلازىمەتنىڭ ھۆججەت تەلىپى ۋە يوللاش ئۇچۇرىغا قاراڭ. سىغىم ۋە بىر تەرەپ قىلىش ۋاقتى دىسكا، مەزمۇن، تەھلىل ۋە ئىندېكسقا باغلىق. يوللاشتىن كېيىن ئىلگىرىلەشنى تەكشۈرۈپ، ئىزدەش تەييار بولغاندا ئىشلىتىڭ. ھۆججەت سانى ۋە ئىندېكس كۆلىمى مەنبە سەرپىياتى ۋە ئىزدەش ئىقتىدارىغا تەسىر كۆرسىتىدۇ.
