ھېشى AI ھەققىدە

يەرلىك ئالدىنلىق، بىخەتەر ۋە ئىشەنچلىك، تولۇق ستاك ئوچۇق كودلۇق AI Agent قورال زەنجىرى ئېكوسىستېمىسى. ئىنژېنېرلىق مۇقىملىقى بىلەن چوڭ مودېلنى شەخسىي ياردەمچىڭىزگە ئايلاندۇرىدۇ.

7 قەۋەتلىك ئامبار قۇراشتۇرمىسى ~1,600,000 قۇر تولۇق كود 100% يەرلىك ئالدىنلىق Apache-2.0 كېلىشىمى
GitHub تەشكىلاتى ↗ يېڭىلىنىش خاتىرىسى

ئەترەت تونۇشتۇرۇشى

نېمە ئۈچۈن ھېشى AI نى قۇردۇق

ھېشى AI (HexClaw) hexagon-codes ئەترىتى تەرىپىدىن ئېچىلىپ ۋە ئاسرىلىدۇ. بىز يەرلىك ئالدىنلىق، سانلىق-مەلۇمات شەخسىي، تولۇق ستاك ئوچۇق كودلۇق AI Agent قورال زەنجىرىنى قۇرۇپ، ھەممە ئادەمگە چوڭ تىل مودېللىرىنى بىخەتەر ۋە ئۈنۈملۈك ئىشلىتىش ئىمكانى بېرىشنى نىشان قىلىمىز.

بازاردىكى نۇرغۇن ئوچۇق كودلۇق AI Agent لار بىخەتەرلىك ۋە خامچوت كونتروللۇقىدا ئاجىز بولۇپ، ھەقىقىي خىزمەتتە ئىشلىتىش خەۋپلىك؛ تىجارىي مەھسۇلاتلار بولسا يېپىق كودلۇق بۇلۇتتا ساقلىنىپ، سانلىق-مەلۇمات مەخپىيەتلىكى كاپالەتسىز قالىدۇ.

بىز ئوچۇق كودنىڭ كەڭلىكى، كارخانا دەرىجىلىك بىخەتەرلىك، كۆپ سۇپىلىق راۋان باغلىنىش ۋە 100% يەرلىك ئالدىنلىقنى بىر گەۋدىگە جەم قىلدۇق.

ئوچۇق كودلۇق ئېكوسىستېما

تۈر 7 ئامبارغا ئايرىلغان، بىر يۆنىلىشلىك باغلىنىشلىق قۇرۇلما ئىشلىتىدۇ، ھەر بىر قەۋەتنى ئايرىم ئىشلىتىشكە بولىدۇ:

  • toolkit ↗ ئاساسىي قەۋەت
    140,000 قۇر ساپ Go ئۆلچەملىك كۈتۈپخانىسى؛ تاشقى تايىنىش يوق، كەش، شىفىرلاش ۋە توردىن پايدىلىنىدۇ.
    Go Standard Library·تاشقى تايىنىش يوق
  • ai-core ↗ AI ئىقتىدار قەۋىتى
    63,000 قۇر بېكىتىلگەن كۆپ Provider ماسلاشتۇرغۇچ (OpenAI, Claude, DeepSeek, Ollama)، سىڭدۈرۈش ۋە Smart Router.
    كۆپ Provider·ئەقىللىق يۆنىلىش
  • hexagon ↗ Agent يادرولۇق ماتورى
    234,000 قۇر يادرولۇق رامكا، 10 خىل Agent شەكلى، گىراف پىلانلاش، 7 باسقۇچلۇق RAG ۋە <10ms قۇم ساندۇقى.
    10 خىل Agent·گىراف پىلانلاش·قۇم ساندۇقى
  • hexclaw ↗ ئارقا مۇلازىمەت
    752,000 قۇر، يەككە ئىجرا ھۆججىتى؛ 13 خىل ئالاقە يولى، 6 قەۋەتلىك بىخەتەرلىك دەرۋازىسى ۋە 71 ئېغىز.
    بىر ئىجرا ھۆججىتى·13 يول·6 قەۋەت بىخەتەرلىك
  • hexclaw-desktop ↗ ئۈستەلئۈستى خېرىدارى
    412,000 قۇر Tauri ئارقىلىق ياسالغان خېرىدار؛ پاراڭ، ئىش ئېقىمى ۋە K12 تەپەككۇر يېتەكچىسى بىلەن تەمىنلەيدۇ.
    Tauri يەرلىك·ئەستە تۇتۇش ئاز·يەرلىك مەخپىي
  • hexclaw-ui ↗ Web كۆرۈنمە يۈزى
    يېنىك جاۋاب قايتۇرۇشچان Web خېرىدارى، كۆپ سۇپىلىق پاراڭ ۋە ئىش ئېقىمى تەڭشىكى تەمىنلەيدۇ.
    جاۋاب قايتۇرۇشچان·ئېقىم كۆرۈنۈشى
  • hexagon-ui ↗ كۆزىتىش تاختىسى
    Agent كۆزىتىش مەركىزى، چاقىرىش ئىز قوغلاش (Trace)، تەننەرخ ئانالىزى ۋە سىستېما سۈرۈشتۈرۈشنى قوللايدۇ.
    ئىز قوغلاش·تەننەرخ ئانالىزى·DevUI

تېخنىكىلىق قۇرۇلما

ھېشى AI ئۆزىمىز تەتقىق قىلغان Hexagon Agent ماتورىغا ئاساسلىنىدۇ، Tauri + Go تېخنىكا ستاكىنى ئىشلىتىدۇ:

🏗️

5 قەۋەت بىر يۆنىلىشلىك باغلىنىش

ئەڭ تۆۋەن toolkit تىن تارتىپ ai-core، hexagon، hexclaw ۋە خېرىدارغىچە. ئەكسىچە تايىنىش يوق، ھەر بىر قەۋەتنى ئايرىم ئىشلەتكىلى بولىدۇ.

⚡

Go يۇقىرى پاراللېللىق ۋە يەككە ئىجرا ھۆججىتى

Goroutine مىليونلىغان پاراللېل ئېقىمنى بىر تەرەپ قىلىدۇ؛ مۇلازىمېتىر يەككە ھۆججەت بولۇپ، 100ms ئىچىدە قوزغىلىدۇ، Python مۇھىتى تەلەپ قىلمايدۇ.

🛡️

Go سىستېما قۇم ساندۇقى (Docker سىز)

2,713 قۇر Go كودى مەشغۇلات سىستېمىسىنىڭ ئۆزىدىكى مېخانىزمدىن پايدىلىنىپ، 10ms ئىچىدە قوزغىلىدىغان بىخەتەر بوشلۇق قۇرىدۇ.

🔒

6 قەۋەت Fail-Closed بىخەتەرلىك دەرۋازىسى

سالاھىيەت دەلىللەش → سۈرئەت چەكلىمىسى → Token خامچوتى → Prompt قوغداش → PII مەخپىيلەشتۈرۈش → RBAC تەكشۈرۈش.

🧩

10 خىل Agent شەكلى ۋە بىر تۇتاش كۆرۈنمە يۈز

BaseAgent تىن تارتىپ Supervisor كۆپ ئەپكىچە. ھەممىسى Runnable[I,O] ئارقىلىق بىرلەشتۈرۈلگەن، گىراف پىلانلاش ۋە 7 باسقۇچلۇق RAG نى قوللايدۇ.

🌐

13 خىل ئالاقە يولى ۋە 100% يەرلىك

فېيشۇ، دىڭدىڭ، ئۈندىدار، Telegram ۋە Web نى قوللايدۇ؛ سانلىق مەلۇمات پۈتۈنلەي كومپيۇتېرىڭىزدا قالىدۇ، Ollama ئارقىلىق تورسىزمۇ ئىشلەيدۇ.
