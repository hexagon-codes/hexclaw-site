本机或自建服务，按需选择

数据与配置由连接的本机或自建服务保存。使用在线模型时，任务中发给模型的内容会传给对应服务商。 本机与云端怎么选

为任务选择智能体

创建或调整智能体的角色与配置，按任务连接知识、技能和工具；K12 辅导是其中一个专属场景。

检索资料，保留记忆

导入资料后检索正文与来源；查询、纠正、更新或遗忘长期记忆。

连接常用工具

把常用做法存成技能和提示模板，按需要通过 MCP 连接外部工具与服务。

生成文档与媒体

按模型能力生成文档、图片、语音和视频，也能基于已有图片继续修改。文件可查看、下载和再次发送。

安排任务与流程

按计划或 Webhook 发起任务，编排多步工作流，查看运行记录，按任务状态取消或恢复。

三步开始使用

安装应用，连接服务与模型，再交办一个熟悉的任务。
1

下载安装

macOS 推荐使用一行命令安装；也可下载对应系统的安装包。
2

连接服务与模型

选择本机或自建服务，确认可用模型；工具按任务需要配置。
3

交办一个具体任务

发送消息或资料，查看执行过程和结果文件；需要专属角色时，再创建智能体。

系统要求与安装说明

macOS 一行命令安装（推荐）

复制命令到终端运行。当前随包组件需要 macOS 14 及以上，支持 Apple Silicon 与 Intel。

curl -fsSL https://raw.githubusercontent.com/hexagon-codes/hexclaw-desktop/bb3c12ec91eec91798b67c292bc8c85c4481dc2b/install.sh | bash

安装最新公开版本，可能包含预发布版。

也可通过 Homebrew 安装：

brew tap hexagon-codes/tap && brew install --cask hexclaw
