隐私政策

业务数据由所连接的本机或自建云端服务保存；云端模型按任务需要接收相关内容。

数据存储

对话、知识库索引与业务文件由当前连接的 HexClaw 服务保存：本机服务保存在当前设备，自建云端服务保存在服务器。桌面偏好设置保存在当前设备。切换服务不会自动迁移数据；hexagon-codes 不提供用于同步或托管这些数据的官方云端账户服务。

API Key 安全

本机桌面端的 Provider API Key 由 Sidecar 保存到 ~/.hexclaw/hexclaw.yaml，目录权限为 0700、文件权限为 0600，不通过系统钥匙串或浏览器存储另存 Provider 密钥。连接自建云端时，使用云端服务的 Provider 配置和凭据；本机配置不会自动同步到云端。

网络通信

河蟹 AI 仅与您配置或启用的网络服务通信。第三方模型可能接收的内容、知识库文本分块、查询文本及用户控制，详见《第三方 AI 服务与数据说明》。

完全离线模式

连接本机服务、仅使用 Ollama 等本地模型并关闭其他网络集成时，相关任务可完全离线运行，模型请求不会离开您的设备。连接自建云端仍需网络，本地运行时位于服务器。

数据收集与追踪

我们不收集用户数据、不追踪用户行为、不投放广告。河蟹 AI 为开源软件，您可随时审计代码以验证上述承诺。

开源与透明

河蟹 AI 采用 Apache-2.0 开源协议发布，完整源代码可在 GitHub 上查阅。我们欢迎社区参与代码审计与贡献。
