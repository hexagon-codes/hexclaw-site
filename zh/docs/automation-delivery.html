河蟹 AI 使用指南

让任务按时运行，把结果送到需要的地方

先完成一次任务，再配置计划；运行成功、文件就绪和消息送达分别检查。

适用版本：当前开发版（2026-10-24 代码基线）。稳定版 v0.5.0 不代表包含本文全部能力，安装前请核对更新日志与对应版本说明。

河蟹 AI 的自动化包含定时任务、Webhook 和工作流。定时任务负责何时执行，Webhook 接收外部事件，工作流把一项任务组织成多个步骤。保存配置之后，还需要确认任务已启用、执行环境持续可用。

选择适合任务的触发方式

需求使用方式需要确认
现在处理一次资料手动执行或工作流试运行本次输入、模型、工具与交付目标。
每天或每周重复完成同一项任务定时任务执行时间、时区、启用状态以及资料来源。
外部系统发生事件后执行Webhook触发地址、鉴权配置、事件输入与绑定的任务。
需要按顺序整理、分析并生成文件工作流步骤输入、所需资源、输出格式与交付位置。

入口位于自动化。也可以在会话里查询、创建或修改定时任务和工作流，明确要求时发起执行。创建计划或保存工作流，不会自动额外运行一次。

先用一次输入把工作流跑通

以下用“把一份进展记录整理成日报”作为任务示例，没有预设已经生成的报告。准备一份可以提供给当前服务的记录，再明确希望保留的事实与输出格式。

把这份进展记录整理成日报。
分为已完成、当前阻塞、明日计划三部分，保留原文日期和负责人。
没有依据的事项不要补写，输出为 Markdown 文件。
  1. 进入自动化 → 工作流，新建工作流。
  2. 配置输入步骤，再添加需要的智能体或工具步骤；后续步骤可以使用本次输入、前一步或指定步骤的结果。
  3. 在输出步骤选择文件格式与交付位置，保存定义。
  4. 点击试运行并提供本次资料，查看各步骤状态、生成文件和交付结果。

试运行会实际调用模型和工具，也会执行已配置的交付。如果此时只想检查文稿，可先把结果保留在会话或指定文件位置，确认内容后再配置消息渠道。更详细的步骤配置见工作流教程。

再配置重复计划或事件触发

一次任务的输入可用，不代表第二天会自动取得新资料。配置计划时，要说明资料从哪里来、读取哪个时间范围，以及缺少资料时如何处理。资料源所需的连接和工具必须在执行任务的服务中可用。

保存定时任务后核对计划时间、时区与启用状态；需要当天立即验证时，另行明确执行一次。绑定 Webhook 时，核对传入内容能否作为该工作流的输入，并按照当前服务提供的触发与鉴权配置接入外部系统。

本机服务需要电脑和服务持续运行。自建云端可以在桌面电脑关机后继续执行，但服务器、模型、工具和交付渠道仍须在线。部署选择见本机与云端说明。

按文件和收件位置配置交付

目标用途检查方式
来源会话或工作流会话在工作台继续查看回答与产物。打开对应会话，检查内容和已就绪文件。
文件输出 PDF、Markdown 或 HTML。下载并打开文件，确认正文、图片及所需附件齐全。
桌面或服务端目录把结果保留到指定位置。核对当前交付方式与目录所在机器，检查实际文件。
钉钉或邮件把结果交给已配置的接收目标。先确认当前服务中的连接与目标，再核对投递记录和接收端结果。

连接云端时，服务器目录不会自动变成桌面电脑的目录。需要向桌面保存文件时，应使用当前版本提供的桌面交付或下载方式，并保持对应客户端可用。

执行完成与渠道接收是不同阶段。邮件服务接受请求不等于收件人已收到，消息平台的接口成功也不能代替接收端查看。把结果交付给其他人前，应先检查收件目标与内容。

失败时处理对应阶段

运行历史保存步骤状态与本次输入。可以离开页面，再从运行记录返回。对于支持续接的失败或中断任务，按运行详情提供的入口继续；已生成的文件和失败的交付分别处理，不必为了重发结果重新做完整任务。

如果状态是“结果未知”，先查看原运行、已有文件和投递记录。确认外部操作结果后再处理，避免重复计费或重复发送。停止当前等待也不表示已经撤销外部操作。

启用计划前，检查第一次结果

  • 报告是否只使用本次资料，日期、人员和结论是否准确。
  • 文件能否下载并打开，正文与必要图片、附件是否完整。
  • 产物是否在指定目录或会话中，渠道接收端是否看到了正确内容。
  • 下次运行所需资料、模型、工具和连接是否仍然可用。

若失败发生在模型调用或附件处理，可继续查看媒体生成与恢复说明；连接状态和日志排查见常见问题。
