快捷键参考

桌面应用快捷键，以及聊天和工作流中的常用操作入口。

应用快捷键

快速聊天可在应用处于后台时唤起；其余快捷键在河蟹 AI 窗口内使用。

快捷键功能
⌘+Shift+H快速聊天（全局唤起悬浮窗）
⌘+K命令面板（快速搜索/跳转）
⌘+,打开设置
⌘+N新建会话

对话页面

快捷键功能
Enter发送消息
Shift+Enter换行

搜索会话使用会话列表上方的搜索框；导出使用会话工具栏的下载按钮；停止当前回复使用输入区的停止按钮。输入法选字期间，Enter 用于确认输入，不会直接发送。

工作流操作

在「自动化 → 工作流」中，通过编辑器的按钮保存工作流、增删或调整步骤顺序。操作流程见工作流教程。文本输入框中的撤销与重做作用于正在编辑的文字。

导航

快捷键功能
⌘+1Chat（对话）
⌘+2Agent
⌘+3知识库
⌘+4自动化
⌘+5连接中心
⌘+6能力
⌘+7日志
⌘+8设置
⌘+\折叠/展开侧边栏

系统托盘

操作功能
左键点击托盘图标打开/聚焦主窗口
右键点击托盘图标弹出菜单（打开、快速聊天、日志、设置、退出）

命令面板

按 ⌘ + K 打开命令面板，支持以下操作：

导航命令

命令说明
Chat跳转到聊天页
Agent跳转到 Agent 管理
知识库跳转到知识库（文档 / 记忆）
自动化跳转到自动化（任务 / Webhook / 工作流）
连接中心跳转到通道与账号、数据连接器
能力跳转到技能 / MCP / Prompt
日志跳转到实时日志
设置跳转到设置页

操作命令

命令说明
新建对话创建新会话并跳转到聊天页
切换主题在亮色/暗色模式之间切换

输入关键词可快速搜索过滤命令。

提示：macOS 使用 ⌘，Windows/Linux 对应 Ctrl。
