添加服务商

  1. 进入 设置 → 模型服务
  2. 点击 "添加服务商"
  3. 选择类型（OpenAI / DeepSeek / ...）
  4. 填入该服务商的 API Key；配置保存到当前连接的服务，存储方式见下文
  5. （可选）修改 Base URL（适用于代理或私有部署）
  6. 保存

模型能力标识

能力按具体模型配置，不能用一个服务商的名称推断其所有模型都支持同样的输入和输出：

能力用途
text / code文本对话与代码生成；默认聊天模型需要具备 text 能力
vision读取和理解输入图片，不等于生成或编辑图片
video理解输入视频，不等于生成视频
audio模型支持的音频输入与回应；语音转写、朗读需各自可用的服务
image_generation生成图片；编辑已有图片还需对应模型和接口支持
video_generation生成视频，按任务状态取得产物
embedding将内容转为向量，供知识检索使用，不作为普通聊天模型

在模型配置中确认用途，再选择聊天或专用媒体模型。能力未分类不代表已经支持全部用途；模型列表、能力声明和一次具体调用成功也分别代表不同事实。思考开关与强度由具体模型支持情况决定。

Ollama 本地部署

配置图片、语音或视频任务前，可先查看媒体生成指南，区分理解、生成与编辑需要的模型能力。

Ollama 可在模型下载完成后本地推理；整个任务是否离线，还取决于是否使用联网工具、云模型或外部服务。

# 安装 Ollama
brew install ollama    # macOS
# 或访问 ollama.com 下载

# 启动并下载模型
ollama serve
ollama pull llama3.1
ollama pull qwen2.5
ollama pull deepseek-r1

在河蟹 AI 中添加 Ollama 服务商，Base URL 填 http://localhost:11434/v1，无需 API Key。

API Key 安全

本机桌面端的 Provider API Key 由 Sidecar 保存到 ~/.hexclaw/hexclaw.yaml，目录权限为 0700、文件权限为 0600，不通过系统钥匙串或浏览器存储另存 Provider 密钥。连接自建云端时，使用云端服务的 Provider 配置和凭据；本机配置不会自动同步到云端。

测试连接

在服务商卡片使用测试功能，检查所选地址、凭据和模型是否能完成实际调用。测试可能使用服务商额度；查看返回结果和错误详情，连接成功不代表该服务商下所有模型、媒体或工具能力均已验证。

自动模型选择

使用自动选择时，当前服务按默认模型、任务所需能力和路由设置选取模型；专用媒体任务按对应能力选择。发生可切换的模型故障时，服务可尝试符合条件的备用 Provider。

实际是否切换取决于失败类型、可用备用模型和任务状态，并非所有失败都会重发。查看本次执行记录中的实际模型；外部操作结果未知时，先查询原任务，避免重复生成或发送。
