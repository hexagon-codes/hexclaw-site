河蟹 AI 使用指南

本机还是云端，先看任务在哪里运行

自己电脑上的资料处理，从本机开始；需要持续运行的计划任务，再考虑自建云端服务。

适用版本：当前开发版（2026-10-24 代码基线）。稳定版 v0.5.0 不代表包含本文全部能力，安装前请核对更新日志与对应版本说明。

河蟹 AI 桌面端可以连接应用管理的本机服务，也可以连接你自行部署的 HexClaw 云端服务。这个选择决定任务在哪里执行、数据存在哪里，以及工具能访问哪些文件。

按使用场景选择服务

你要做的事建议选择需要准备
处理当前电脑的文件，在桌面上查看和保存结果本机服务保持电脑与本机服务运行，配置任务需要的模型和工具。
电脑关机后仍要执行计划，或通过绑定的消息渠道交办任务自建云端服务持续在线的服务器、可用模型、工具与消息连接。
使用 Ollama 等本地模型先确认模型运行在哪台机器让执行任务的 HexClaw 服务能访问模型地址；桌面位置不决定模型位置。

本机服务随电脑关闭而停止。云端任务可以在桌面电脑关机后继续，但服务器、模型和所需外部服务仍须可用。需要“7×24”运行时，应一起考虑这些条件。

连接服务，再配置它使用的模型

  1. 安装桌面端，首次启动时选择本机服务，或填写自建云端服务地址与访问令牌。
  2. 查看当前服务的连接状态。后续可以从侧栏底部的服务状态入口切换，也可以在设置的服务卡片查看。
  3. 进入设置 → 模型服务，配置当前服务使用的模型；云端已经配置默认模型时，可以直接发起任务。
  4. 先完成一项小任务，检查实际回答或文件，再接入需要的知识库、MCP 和消息渠道。

安装与平台依赖见快速上手。选择模型前，可查看模型服务商配置，区分在线模型、Ollama 与专用媒体模型。

数据跟着所选服务保存

内容本机服务自建云端服务
会话、学习记录、知识资料与生成产物保存在当前设备的服务数据中。保存在部署服务器的服务数据中。
模型配置与连接使用本机服务的配置。使用服务器的配置，不自动继承桌面本机配置。
文件工具访问范围按工具配置和权限访问本机环境。访问服务器环境，不会自动获得桌面电脑的文件系统。

本机和云端的数据分别管理。切换服务不会自动搬运或合并会话、学习记录、知识库、模型配置和连接。如果切换后没有看到原来的会话，先确认当前连接的服务，再判断是否需要迁移。

上传附件与访问本机目录是两件事

假设你想让 Agent 整理电脑里的发票：本机服务可以通过已配置的文件工具访问对应目录；连接云端服务时，同样的目录名称指向服务器环境。需要把资料提供给云端时，应使用当前任务支持的附件或文件传递方式，并确认文件已被接收。

模型地址里的 localhost 也指执行 HexClaw 服务的机器。云端服务填写 http://localhost:11434/v1，访问的是服务器上的 Ollama，不是桌面电脑上的 Ollama。

本机服务也可以使用在线模型

“本机服务”说明 HexClaw 在哪里运行，不代表每次推理都在本地。选用在线模型时，任务所需的提示词、上下文、图片或文件内容会发送给所选服务商；联网搜索、MCP 和消息渠道也会按任务与外部系统通信。

要离线处理任务，需要让模型和所需工具都能在本机工作。软件开源与模型调用费用是不同事项，在线模型和外部服务按各自账户计费。相关数据路径见第三方 AI 服务说明。

切换前确认保存位置，迁移前准备备份

需要保留完整服务数据时，备份范围应覆盖该部署实际使用的数据库、资料与产物目录、配置；只复制桌面偏好不能替代业务数据备份。单个会话可以按需导出，家庭学习档案另有 .hexbak 归档与恢复。

从一种部署方式换到另一种方式后，重新检查模型和连接是否可用，再用已有资料完成一项任务。涉及消息投递时，还要核对目标渠道的实际接收结果。
