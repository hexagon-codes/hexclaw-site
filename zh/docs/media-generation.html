河蟹 AI 使用指南

在会话里生成图片、语音与视频

选择支持对应任务的模型，再描述需要的结果。生成后查看预览和保存的文件，需要继续修改时回到原会话。

适用版本：当前开发版（2026-10-24 代码基线）。稳定版 v0.5.0 不代表包含本文全部能力，安装前请核对更新日志与对应版本说明。

河蟹 AI 使用同一个会话输入框接收文字、附件和媒体任务。可以让 Agent 调用已配置的媒体工具，也可以选择专用图像或视频生成模型发送需求。能否完成具体任务，取决于对应模型、服务商和工具的实际能力。

先分清“看懂”与“生成”

任务需要的能力操作前确认
描述图片、识别图片里的内容图像理解当前模型支持图片输入，附件满足服务商要求。
根据文字生成图片图像生成已配置可用的图像生成模型或工具。
基于已有图片修改内容图片编辑模型支持参考图片或编辑输入，原图已经附在任务中。
分析视频与生成视频分别需要视频理解、视频生成理解能力不代表能够生成；输入、时长和输出格式按对应服务要求。
语音输入、朗读、音频对话分别需要语音识别、语音合成、音频对话录音权限与对应服务可用，不能只凭模型名称判断。

同一服务商的模型也可能各不相同。先在模型服务商设置检查模型与能力配置；能进行文本对话，不代表一定支持生图或音频输出。

从一张图片开始

  1. 确认当前连接的本机或云端服务，并配置可用的图像生成模型或工具。
  2. 在会话中说明用途、画面主体、比例和必须保留的内容。下面是需求示例，不是已经生成的案例。
  3. 发送后查看任务进度和工具活动，等待实际图片出现。
  4. 检查图片内容，再使用产物提供的查看、下载或保存入口。

如果需要修改现有图片，先附上原图，再说明“保留什么、改哪里”。例如“保留主体和构图，把背景改成浅色”。只有支持图片编辑的模型才能执行这类请求；单纯把图片描述转成提示词，不等于保留了原图。

语音和视频任务看各自的输入与输出

语音输入会先把录音转成文字，再发送到会话。朗读则把文字转换为可播放语音，需要语音合成服务。音频对话使用已注册的音频对话模型，输入与回应可以包含音频和转写文字。这三种用法需要分别确认配置。

视频生成可能需要等待外部服务处理。查看原任务的进度，产物可用后再播放或保存。视频理解只处理已有视频内容，不应将它当成视频生成入口。时长、尺寸和格式应按所选模型的要求填写，不套用另一家服务商的参数。

生成完成后，检查文件是否真的保存

生成、保存和发送到其他渠道是不同结果。先查看图片或播放音视频，确认内容可用；需要长期保留时，再核对保存状态或下载文件。不要只根据回答里的“已完成”判断。

已经保存的媒体与会话关联。重新打开历史会话时，仍需连接保存它的 HexClaw 服务，且服务端文件仍然存在；只有外部临时链接的历史结果，还受链接有效期影响。切换本机与云端不会自动迁移这些文件。

文件显示就绪后，可以继续查看、下载或在支持的任务中再次使用。发送到消息渠道时，接收方能否直接预览或播放，还取决于渠道支持的类型。

中断后回到原任务，先确认发生了什么

看到的情况下一步
仍在生成或等待外部服务查看原任务进度，不重复提交同一生成请求。
生成已完成，保存或投递失败保留已有产物，按对应保存或投递入口处理，避免重新生成。
任务已中断，界面提供恢复入口沿原请求恢复；是否可恢复以该任务状态为准。
结果未知查询原任务记录与已有产物，确认是否已经生成或发出，再决定下一步。

停止等待不代表外部服务已经取消生成，也不代表已发生的计费或投递被撤销。结果未知时直接重发，可能重复生成或重复发送。

把检查标准写进需求里

插图需要检查主体、构图和文字；朗读需要检查转写、发音和是否完整；视频需要检查内容、时长与播放。模型输出仍要由使用者核对。准备自动保存或发送时，可继续查看定时任务与结果交付。
