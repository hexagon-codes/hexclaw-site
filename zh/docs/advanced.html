高级功能

MCP、知识库 RAG 与记忆、自动化（定时任务 / Webhook / 工作流）、连接中心与数据连接器、技能、Prompt 库与安全网关。

实际可用功能取决于安装版本、当前连接的服务和已启用的能力；已有截图用于说明入口。

在会话里使用与管理资源

可以直接询问已经配置了哪些资源，也可以把创建、安装、修改、启用和运行交给 Agent。操作沿用当前权限和设置，资源状态以当前服务的实际结果为准。

在会话里说可以完成的事
“哪些 MCP 已接通？我有哪些工作流和智能体？”查询已配置资源、连接状态及详情；也能查 Skill、Prompt、记忆、知识内容与会话历史。
“把这段内容加入知识库。”保存文本并交给知识库处理；后续是否能检索，以实际处理和索引状态为准。
“记住这个偏好；把旧信息改掉。”新增、更新、删除或置顶长期记忆。
“把这套做法整理成技能并启用。”创建或修改 Skill，完成保存、启用和加载；也可以搜索、安装已有 Skill 或 MCP。
“把这段提示保存到 Prompt 库；用这个模板创建助手。”创建、修改和启停 Prompt，按模板或给定配置创建、更新智能体。
“每天九点整理资料；今天先执行一次。”创建或修改定时任务，查询、暂停、恢复、删除任务；明确要求立即执行时发起一次运行。
“把这套步骤保存为工作流，再运行一次。”创建或修改工作流定义，按明确指令发起执行并查看结果；也可管理 Webhook 绑定与启用状态。

Prompt 库、智能体和工作流也有各自的管理页面，与会话操作使用同一份资源。只要求查询时不会运行；只要求保存草稿时不会启用。保存、加载、连接、执行和交付分别按实际状态反馈。

MCP 协议集成

Model Context Protocol（MCP）让 AI Agent 能调用外部工具和服务。

注册 MCP 服务器

  1. 进入 能力 → MCP 标签页
  2. 点击 "添加服务器"
  3. 填入服务器名称和连接地址
  4. 选择协议类型：stdio / sse / streamable_http
  5. 连接后自动发现可用工具

连接成功后，MCP 工具可以分配给 Agent 使用。实时显示连接状态（connected / disconnected / error）。

也可以在会话中查询已配置的 MCP 与可用工具，或搜索、安装现成的 MCP 服务。外部服务仍需要相应账号、连接配置和授权。

MCP 服务器配置示例

以下示例说明 Filesystem MCP 的启动命令与参数。在添加服务器时选择 stdio，对应填写 command 和 args，将 /path/to/your/projects 替换为要访问的实际目录；运行服务的机器需已安装 Node.js 与 npm。若连接云端服务，这个目录属于云端机器。

{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem@2026.7.10", "/path/to/your/projects"]
    }
  }
}

知识库（RAG）

上传文档建立自己的知识库，Agent 按当前任务检索相关内容与来源。知识库存放在当前连接的本机或云端服务中。

支持格式

  • PDF、DOCX、Markdown、TXT 文件
  • 自动分块（chunking）和向量嵌入
  • 语义搜索检索

使用流程

  1. 进入 知识库 页面
  2. 上传文档 — 支持批量上传
  3. 查看处理与索引进度，等待文档达到可检索状态
  4. 在对话中，Agent 按任务检索相关内容作为上下文

上传成功、原件已保存和检索就绪是不同状态。也可以让 Agent 将会话中的文本加入知识库；保存后仍应查看实际处理结果，失败或中断时按任务提供的恢复入口处理。

语义记忆

长期记忆保存需要跨会话使用的事实与偏好。自动捕获按当前设置运行，也可以在会话里明确要求记住、更正或遗忘某条信息。

  • 自动捕获 — 启用后，从对话中提取适合长期保留的信息
  • 语义搜索 — 在 知识库 → 记忆 标签页按关键词或语义检索
  • 类型过滤 — 按记忆类型筛选
  • 手动管理 — 查看、删除、批量清理
  • 会话管理 — 新增、更新、删除、置顶或取消置顶；按实际保存结果反馈

定时任务（Cron）

让 Agent 按计划自动执行任务。

创建定时任务

  1. 进入 自动化 → 任务 标签页
  2. 点击 "创建任务"
  3. 选择执行 Agent、设置 Cron 表达式、填写提示词
  4. 启用任务
# Cron 表达式示例
0 9 * * *      每天早上 9 点
0 */2 * * *    每 2 小时
0 9 * * 1-5    工作日早上 9 点

支持手动触发、执行历史查看、心跳监控。

也可以直接描述执行时间和任务内容，让 Agent 创建或修改定时任务；随后查询、暂停、恢复或删除，明确要求时立即执行。创建计划不会自动额外运行一次。自动化结果按配置的目标交付，执行状态和投递结果分别查看。需要多步处理时，可使用工作流。

Skills 与 ClawHub 市场

在 能力 → Skills 中管理本地技能，从当前服务提供的技能市场安装新能力，也可通过本地文件或 URL 安装：

  • 分类：沟通、效率、开发、数据
  • 安装：一键安装，按 Agent 启用/禁用
  • 查找：按分类和关键词查找，查看作者、版本与所需依赖
  • 配置：部分技能支持自定义参数

在会话中可以搜索、安装、移除或列出已有 Skill，也可以创建或修改自己的技能。明确要求“保存并启用”时，Agent 按当前权限完成保存、激活和加载；只要求草稿时仅保存草稿。已安装、已启用和当前可调用的状态分别说明。

Prompt 库

在 能力 → Prompt 库 中统一管理可复用命令和 Prompt 片段，可随时启停、编辑或删除。

也可以在会话中查询、创建和修改 Prompt，明确需要启用或停用的条目；未要求改变的模型、工具范围和开关保持原值。

安全网关

桌面端的工具确认与执行范围在 设置 → 自动化权限 中管理。下表的网关检测项属于当前 HexClaw 服务的部署配置，按服务端文档与实际配置维护。

本机桌面服务启动时默认关闭网关的提示词注入检测、PII 检测和内容过滤；自建服务按实际部署配置启用。PII 检测不等于自动脱敏，不能据此认为发送给模型的原文已被改写或移除。数据发送范围见第三方 AI 服务说明。

功能说明
安全网关启用/禁用安全检查
提示词注入检测自动检测并拦截恶意提示词
PII 检测检测个人敏感信息，不代表自动改写或移除原文
内容过滤过滤不当内容
Token 上限单次请求最大 Token 数（256 ~ 128,000）
速率限制每分钟请求数（1 ~ 600 RPM）

模型思考与资料检索

在会话输入框底部选择模型，并按该模型的能力调整思考设置。部分模型自动控制思考，部分提供开关或强度选项；不需要切换到另一个聊天模式。

  1. 明确任务 — 提供问题、资料范围和期望的输出格式
  2. 调用资料与工具 — 需要联网或知识检索时，使用当前已连接的工具和知识库
  3. 核对结果 — 查看实际工具活动、引用来源和最终产物

只有模型返回思考内容时，界面才会展示相应内容。开启思考不会自动启用联网搜索，也不能替代来源核验。需要固定多步流程时，可在工作流画布中组织步骤。

连接中心 · IM 通道

河蟹 AI 支持连接多种即时通讯平台，让你通过手机消息远程与 AI 对话。进入 连接中心（侧栏「连接」分区）的「通道与账号」配置：

平台配置项说明
飞书App ID + App Secret在飞书开放平台创建企业自建应用
钉钉App Key + App Secret + Robot Code在钉钉开放平台创建内部应用
企业微信Corp ID + Agent ID + Secret在企业微信管理后台创建自建应用
微信App ID + App Secret + Token需要微信服务号
SlackBot Token + Signing Secret在 Slack API 创建 App
DiscordBot Token在 Discord Developer Portal 创建 Bot
TelegramBot Token通过 @BotFather 创建

当前主线服务在保存已启用账号时会启动或重新连接该账号；查看账号卡片的状态和错误提示，按需使用连接测试。连接成功与消息实际投递是不同结果，接收目标和平台回执也需要核对。旧安装版本如提示需重启，则按该版本提示操作。

数据连接器（MySQL / Redis 等）

在 连接 页的「数据连接器」中管理数据库与缓存连接：

  • 查看连接类型、地址、数据库与当前连接状态
  • 通过测试确认连接可用，再交给 MCP 工具只读访问
  • 未完成的连接会明确标记为「未配置」，不会混入可用连接

Webhook 触发器

在 自动化 → Webhooks 中创建入站触发器，让外部系统安全地触发任务、Prompt 或智能体实例：

  • 签名校验 — HMAC-SHA256 与独立 Secret
  • 防重放 — 校验时间窗口与 nonce，重复事件返回原回执
  • 事件绑定 — 按触发器绑定任务、Prompt 或智能体
  • 事件记录 — 查看最近回执、失败投递与可重试状态

日志与可观测性

日志页集中展示实时运行记录，可按级别、域与关键词筛选，并查看运行状态与告警数量。
