团队介绍

为什么打造河蟹 AI

河蟹 AI（HexClaw）由 hexagon-codes 团队开发维护。我们致力于构建本地优先、数据私有、全栈开源的 AI Agent 工具链，让每个人都能安全、高效地使用大语言模型。

市面上的 AI Agent，开源的大多在安全防护、限流与 Token 成本控制上近乎裸奔，个人与团队不敢在真实工作流中重用；商业产品虽然合规但多为闭源云托管，数据出境不可控；海外项目又普遍缺少对国内主流协同通道（飞书、钉钉、企微等）的原生支持。

我们坚持将开源产品的功能广度、商业级的安全确定性、主流协同通道原生连接与 100% 本地优先部署融合为一。历经持续打磨，从底层通用库、Agent 核心引擎到桌面客户端，完整构建起全栈自研的 AI Agent 基础设施。

开源生态

项目采用 7 个仓库分层解耦的架构，各层严格单向依赖，每一层均可作为独立模块被复用：

  • toolkit ↗ 基础设施层
    14 万行纯 Go 标准库实现，零外部依赖；为全生态提供通用缓存、强加密、网络与并发协程池等底层基石。
    Go 标准库·零外部依赖
  • ai-core ↗ AI 能力底座
    6.3 万行统一多 Provider 适配层（OpenAI / Claude / DeepSeek / Ollama 等），内置 Embedding 抽象与 Smart Router 智能路由探测。
    多 Provider 适配·智能路由
  • hexagon ↗ 核心 Agent 引擎
    23.4 万行核心框架，内建 10 种 Agent 拓扑、图编排（Graph / BSP）、7 环节可插拔 RAG 与 <10ms 原生轻量安全沙箱。
    10 种 Agent·图编排·原生沙箱
  • hexclaw ↗ 应用后端服务
    75.2 万行应用服务层，单二进制交付；集成 13 种主流消息通道（飞书/钉钉/企微等）、6 层安全网关与 71 个端点。
    单二进制·13 通道·6 层安全网关
  • hexclaw-desktop ↗ 桌面原生客户端
    41.2 万行跨平台桌面端，基于 Tauri + Web 原生构建；提供会话、工作流画布、K12 启发式辅导与本地资产沉浸式交互。
    Tauri 原生·低内存占用·本地私有
  • hexclaw-ui ↗ Web 客户端界面
    轻量响应式 Web 客户端，提供跨端会话、工具调用流式展示与工作流节点可视化配置。
    响应式 Web·流式会话
  • hexagon-ui ↗ 链路可观测台
    Agent 可观测性控制面板，支持全链路调用追踪（Trace）、Prompt 实时调试、Token 成本分析与指标监控。
    链路追踪·成本分析·DevUI

技术架构

河蟹 AI 基于自研 Hexagon Agent 引擎，采用 Tauri + Go 全栈技术栈，以「高并发、零依赖、内建安全、原生沙箱」为核心设计原则：

🏗️

五层严格单向依赖

从最底层的 toolkit 基础库，到 ai-core 能力底座、hexagon 框架引擎、hexclaw 服务层，再到顶层桌面与 Web。严格禁止反向依赖与跨层调用，确保每一个模块都能作为通用库脱离生态独立使用。

⚡

Go 原生高并发与单二进制

Agent 的核心瓶颈是网络与工具调用 I/O。利用 Go goroutine 实现百万级并发吞吐；服务端编译为单个二进制文件，一条命令 hexclaw serve 或开箱桌面应用即可秒级启动，免去复杂的 Python 依赖地狱。

🛡️

Go 原生轻量沙箱（免 Docker）

2,713 行代码直接基于操作系统原生底层机制（macOS Seatbelt、Linux Landlock/seccomp、Windows AppContainer）构建沙箱，启动延迟 <10ms，零配置提供文件与网络隔离，彻底替代笨重 Docker。

🔒

6 层 Fail-Closed 企业安全网关

Auth 鉴权 → 令牌限流 → Token 成本预算 → 10 模式 Prompt 注入防御 → 7 类 PII 自动脱敏 → RBAC 权限与审计。任何一层异常即刻阻断，从根源杜绝模型越狱与数据泄露隐患。

🧩

10 种 Agent 拓扑与统一泛型接口

涵盖 BaseAgent、ReActAgent 到 Supervisor 多智能体协同。所有组件抽象为统一的 Runnable[I,O] 泛型接口，支持 Graph 图编排、7 环节可插拔 RAG 与 8 种向量存储后端。

🌐

13 种主流通道与 100% 本地优先

原生适配飞书、钉钉、企微、微信、Telegram、Web 等 13 种通道；数据、向量索引与记忆默认保存在本机磁盘，搭配 Ollama 本地模型可完全断网离线运行，核心隐私与数据自主掌控。
