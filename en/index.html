Product capabilities

Combine agents, knowledge, tools and automation for a task. Follow progress and keep results you can reuse.
Product overview (Chinese PDF)

Choose a local or self-hosted service

Your connected local or self-hosted service stores data and configuration. Online models receive the content sent to them for a task.

Choose an agent for the task

Create agents with their own roles and configurations. Connect knowledge, skills and tools; K12 tutoring is one specialized scenario.

Find sources and manage memory

Search imported documents with their sources. Inspect, correct, update or delete long-term memories.

Connect your tools

Save repeatable methods as skills and prompt templates. Connect external tools and services through MCP as needed.

Create documents and media

Use supported models to create documents, images, audio and video, or edit an existing image. View, download and resend files.

Schedule tasks and workflows

Start tasks on a schedule or through webhooks, arrange multiple steps and inspect run history. Cancel or resume supported tasks.

Get started in three steps

Install the app, connect a service and model, then try a task you know.
1

Install the app

On macOS, use the recommended one-line installer, or download a package for your system.
2

Connect a service and model

Choose a local or self-hosted service and confirm an available model. Connect any tools the task needs.
3

Try a specific task

Send a message or source material, then inspect progress and output files. Create an agent when you need a specialized role.

Download & install

The software is free and open source. Online models and external services may charge separately.

System requirements and installation

macOS one-line install (recommended)

Copy the command into Terminal and run it. Current bundled components require macOS 14 or later; Apple Silicon and Intel are supported.

curl -fsSL https://raw.githubusercontent.com/hexagon-codes/hexclaw-desktop/bb3c12ec91eec91798b67c292bc8c85c4481dc2b/install.sh | bash

Installs the latest public release, which may be a prerelease.

Or install with Homebrew:

brew tap hexagon-codes/tap && brew install --cask hexclaw
